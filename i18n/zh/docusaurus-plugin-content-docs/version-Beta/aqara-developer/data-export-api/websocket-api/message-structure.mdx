# 消息结构说明

## AuthRequest

### 描述

**WebSocket 鉴权请求**

Studio 自身域名地址和局域网 Studio 环境的首包认证方式；生产或云端环境不使用。

### 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | string | 是 | 固定值：[`AuthRequest`](#authrequest)。 |
| `version` | string | 是 | 固定值：`v1`。 |
| `msgId` | string | 是 | 请求使用的非空标识，应至少在当前连接尚未完成的请求中保持唯一；正常响应使用相同 msgId 关联，服务端推送的 msgId 仅用于链路追踪，不等同于订阅请求 msgId，也不保证全局唯一。<br />最小长度：1。最大长度：64。 |
| `data` | object | 是 | 业务参数。 |
| `data.authType` | string | 否 | 鉴权方式。请传入 token。<br />固定值：`token`。默认值：`token`。 |
| `data.token` | string | 是 | 请使用格式：`Bearer <Token>`，其中 `<Token>` 为 Aqara Studio 获取的原始 Token。切勿将此 Token 记录或暴露于日志。 |

### 示例

**bearerToken**

```json
{
  "type": "AuthRequest",
  "version": "v1",
  "msgId": "10001",
  "data": {
    "authType": "token",
    "token": "<accessToken>",
    "clientId": "<clientId>"
  }
}
```

## UnsubscribeAllRequest

### 描述

**取消全量/设备级订阅**

清理全部或指定设备的数据订阅，并同时清理当前会话的 Trait 订阅。
不清理独立事件订阅、精确对象事件订阅，也不关闭认证连接默认接收的 DEVICE_ADDED、DEVICE_REMOVED。

### 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | string | 是 | 固定值：[`UnsubscribeAllRequest`](#unsubscribeallrequest)。 |
| `version` | string | 是 | 固定值：`v1`。 |
| `msgId` | string | 是 | 请求使用的非空标识，应至少在当前连接尚未完成的请求中保持唯一；正常响应使用相同 msgId 关联，服务端推送的 msgId 仅用于链路追踪，不等同于订阅请求 msgId，也不保证全局唯一。<br />最小长度：1。最大长度：64。 |
| `data` | array&lt;string&gt; 或 null | 否 | 设备 ID 列表。为空或 null 时表示取消全部设备数据和 Trait 订阅。<br />若当前为全部设备订阅，按特定设备取消订阅不会生效，需传空值取消全部设备数据订阅。<br />同一连接内，[UnsubscribeAllRequest](#unsubscribeallrequest) 会同时清理此前通过 [SubscribeTraitValueRequest](#subscribetraitvaluerequest) 建立的 Trait 订阅。<br />按特定设备取消订阅只取消设备级订阅，不等同于关闭当前连接的全部推送。<br />本请求不清理 [SubscribeEventRequest](#subscribeeventrequest) 或 [SubscribeObjectEventRequest](#subscribeobjecteventrequest) 建立的规则，也不关闭默认 DEVICE_ADDED、DEVICE_REMOVED 推送。<br />默认值：`null`。 |

## AlarmEvent

## ObjectEvent

### 描述

**对象事件推送**

设备增删默认推送；空间、自动化、独立场景及空间关联变化按精确对象订阅投递。当前 19 类对象事件均提供示例。

DEVICE_ADDED、DEVICE_REMOVED 在认证连接建立后默认推送。

DEVICE_SPACE_UPDATED、三类空间变化、四类自动化变化、四类场景变化以及 AUTOMATION_EXECUTION_RESULT、SCENE_EXECUTION_RESULT，均只投递给命中 eventType、objectId 和当前权限的 SubscribeObjectEventRequest 会话。

DEVICE_ENDPOINT_*、DEVICE_TRAIT_PARAMETER_UPDATE 继续跟随现有设备数据订阅。

独立场景通过 /scenes 管理，变化通知使用四类 SCENE_* 事件，自动化仍使用 AUTOMATION_*；可信类别由服务端判断。数量变化不提供独立事件。新增、删除自动化只发送对应生命周期快照，不额外发送空间关系事件；已有对象仅空间关系变化时发送 AUTOMATION_SPACE_UPDATED，内容与关系同时变化时两类事件都可能收到。

独立场景使用 SCENE_ADDED/REMOVED/UPDATED/SPACE_UPDATED，不再双发 AUTOMATION_*；sceneId 仍是 auto_ 前缀。旧自动化手动入口仍归自动化。场景定义比较排除空间，空间与定义同批变化产生两条不同 eventId 的通知。

自动化快照的 manualTriggers 包含 triggerNodeId 和 triggerName；手动触发入口添加、删除或重命名通过 AUTOMATION_UPDATED 返回完整列表。按完整列表替换缓存，空数组清空旧入口；无需新增事件订阅类型。

msgId 只用于链路追踪。新版业务通知按 studioId + eventId 幂等；旧对象变化缺少公共身份时按对象状态幂等处理，不应仅按 objectId、eventType 或 time 去重。

两类动作结果及四类独立场景变化都必须携带公共层 studioId 和 eventId。同一逻辑通知跨通道和 HTTP 重试保留身份；动作结果可按接收者权限裁剪字段。按 studioId + eventId 幂等；executionId 仅关联执行，不可用时显式为 null。新订阅可能收到公共队列尚未分发的记录，不提供历史回放。

新版所有业务通知成对携带 studioId/eventId；普通历史报文允许缺省以兼容旧生产者。普通请求响应不引用本结构。执行结果与四类新场景对象事件另有强制身份约束。

## UnsubscribeObjectEventRequest

### 描述

**取消空间、设备空间关系和自动化对象事件订阅**

按当前 WebSocket 会话移除指定对象规则或清空指定事件类型。

objectIds 非空时只移除指定对象；不传、为 null 或空数组时清空对应 eventTypes 的全部对象规则。
全量订阅不支持排除部分对象；要从全量切换为指定对象，应先清空事件类型，再发送新的指定对象订阅。

### 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | string | 是 | 固定值：[`UnsubscribeObjectEventRequest`](#unsubscribeobjecteventrequest)。 |
| `version` | string | 是 | 固定值：`v1`。 |
| `msgId` | string | 是 | 请求使用的非空标识，应至少在当前连接尚未完成的请求中保持唯一；正常响应使用相同 msgId 关联，服务端推送的 msgId 仅用于链路追踪，不等同于订阅请求 msgId，也不保证全局唯一。<br />最小长度：1。最大长度：64。 |
| `data` | array&lt;object&gt; | 是 | 必须包含 1 至 100 个取消项；空数组是参数错误，不表示取消全部事件类型。<br />objectIds 不传、null 或空数组时，清除对应 eventTypes 下当前会话的全部对象规则；非空时只移除指定对象。<br />最少 1 项。最多 100 项。 |
| `data[].eventTypes` | array&lt;string&gt; | 是 | 最少 1 项。元素不可重复。<div><span>元素枚举</span><ul className="enum-list"><li><code>DEVICE_SPACE_UPDATED</code>: 设备所属空间发生变化。</li><li><code>SPACE_ADDED</code>: 空间新增。</li><li><code>SPACE_REMOVED</code>: 空间删除。</li><li><code>SPACE_UPDATED</code>: 空间更新。</li><li><code>AUTOMATION_ADDED</code>: 自动化新增。</li><li><code>AUTOMATION_REMOVED</code>: 自动化删除。</li><li><code>AUTOMATION_UPDATED</code>: 自动化更新。</li><li><code>AUTOMATION_SPACE_UPDATED</code>: 自动化所属空间变化。</li><li><code>AUTOMATION_EXECUTION_RESULT</code>: 自动化执行结果。</li><li><code>SCENE_EXECUTION_RESULT</code>: 场景执行结果。</li><li><code>SCENE_ADDED</code>: 场景新增。</li><li><code>SCENE_REMOVED</code>: 场景删除。</li><li><code>SCENE_UPDATED</code>: 场景更新。</li><li><code>SCENE_SPACE_UPDATED</code>: 场景所属空间变化。</li></ul></div> |
| `data[].objectIds` | array&lt;string&gt; 或 null | 否 | 对象 ID 列表。按事件类型填写设备、空间、自动化或场景 ID。 <br />订阅时，不传、null 或空数组表示当前权限范围内全部对象；非空时只匹配指定对象。<br />取消订阅时，不传、null 或空数组表示清空对应 eventTypes，非空时只移除指定对象。<br />同一 WebSocket 会话在每个 eventType 下最多累计订阅 1000 个不同 objectId。<br />objectIds 非空时，同一项的 eventTypes 必须属于同一公开 ID 家族（设备、空间、自动化/场景）；SPACE_ADDED、AUTOMATION_ADDED、SCENE_ADDED 只支持全部对象语义。<br />最多 1000 项。元素不可重复。元素最小长度：1。 |

## CommandReport

### 描述

随 v1 设备级或全量设备订阅发送，保留原网关结果，不表示设备物理动作已完成。

新版所有业务通知成对携带 studioId/eventId；普通历史报文允许缺省以兼容旧生产者。普通请求响应不引用本结构。执行结果与四类新场景对象事件另有强制身份约束。
