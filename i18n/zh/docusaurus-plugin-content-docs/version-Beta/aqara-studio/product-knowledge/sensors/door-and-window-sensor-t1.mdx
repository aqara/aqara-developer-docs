# 门窗传感器 T1


## 产品介绍

Aqara门窗传感器 T1是一款基于Zigbee 3.0无线通信协议的检测如门、窗、抽屉、衣柜等物体的开合状态传感器，内置了高精度干簧管，可以准确检测门窗开合。Aqara门窗传感器 T1可以根据检测门窗开合状态的变化为自动化条件，联动网关或其他设备执行多种智能场景。

:::tip
- 本产品需接入 Aqara Studio 或 Aqara Life 使用。
- 薄片型磁铁可用于代替磁铁，如玻璃门等较狭窄安装场景。
:::

### 部件与按键说明

| 部件 | 说明 |
| -- | -- |
| 传感器主体 | 检测开合状态，粘贴于开合区域固定面 |
| 磁铁 | 与传感器主体配合，粘贴于开合区域活动面 |
| 薄片型磁铁 | 可用于代替磁铁，适用于玻璃门等较狭窄安装场景 |
| 指示灯 | 提示设备入网、通讯及工作状态 |
| 重置键 | 长按5s：重置/入网；单击：有效通讯距离验证/设备查找功能 |

## 设备入网

入网前，请依照网关说明书完成网关接入，并确保已准备好 Aqara Studio 网页端平台或 Aqara Life App。本产品可通过以下任一方式添加设备。

### 通过 Aqara Life App 添加

请在 Aqara 官网或 Apple App Store / Google Play 应用商城搜索并下载最新版本的 Aqara Life App。通过 App 指引的“添加设备”流程完成设备添加。

### 通过 Aqara Studio 网页端添加

请在 Aqara Studio 网页端平台登录后，按照网页端指引完成设备添加。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/door-and-window-sensor-t1-image1.png" alt="通过 Aqara Studio 网页端或 Aqara Life App 添加设备"  style={{ width: '70%' }} />

:::tip
- 请确保添加过程中设备处于配网模式（指示灯呼吸状态），如指示灯处于其他状态，可按住重置键 5 秒钟直到 LED 指示灯开始闪烁，然后释放，设备将再次进入入网配对模式。
- 本产品长按重置键 5 秒后，指示灯蓝色快闪 3 次表示已进入搜网（配网）状态；入网成功快闪 2 次，入网失败长亮 1 秒。
- 如添加失败，请将设备移近网关后重试。
- 如需帮助请查询：www.aqara.com/support。
:::

### 固件升级

为保证最佳使用体验，请在设备完成添加后，先在 Aqara Life App 或 Aqara Studio 网页端的设备设置页更新设备固件到最新版本后开始使用。

## 安装方法

有效距离验证：在预选的安装位置，单击设备重置键，网关发出提示音，表明设备与网关之间可以有效通讯。

:::tip
为了确保无线通信稳定，请避免安装在金属表面。
:::

1. 撕下胶贴保护膜。
2. 安装时尽量对齐主体与磁铁侧边的安装标记线。
3. 分别粘贴在所需开合区域（建议主体安装在开合区域固定面，磁铁安装在活动面，安装间隙在门窗关闭状态下小于22毫米）。

:::tip
请确保粘贴位置表面清洁干燥。
:::

## 常见问题

### Aqara门窗传感器 T1 如何安装？传感器主体和磁铁部分可以左右调换吗？

- 如说明书示意图所示，对齐主体与磁铁的安装标记线，将其中一个安装在门窗固定面，另一个安装在开合面（建议将主体安装于固定面）；
- 主体与磁铁的距离应小于22mm；
- 可左右调换，但必须保证主体与磁铁的安装标记线对齐；
- 由于室内环境复杂，调整网关和门窗传感器的相对位置，可以获得更好的通讯环境；
- 由于金属对无线信号有衰减作用，因此门窗传感器不要安装在门窗的金属部分上。

### 门和门框不在同一平面上如何安装？

把磁铁方向转90度。最好把传感器主体安装在不移动的门框上，磁铁安装在门上，这样可以更好保护传感器。传感器主体和磁铁的距离小于22mm，但同时不能安装得太靠近，以免相接触导致碰撞掉落而损坏。

### Aqara门窗传感器 T1 距离网关多远，才能正常通讯？

在复杂的室内环境，如果门窗传感器和网关之间有墙相隔，需要相应减少两者之间距离，以达到更好的通讯。

### Aqara门窗传感器 T1 连接失败的原因是什么？应该如何重新连接？

可能的原因：

- 操作错误，请参照本说明书「设备入网」章节重新添加设备；
- 距离网关过远，将设备移近网关后重新添加设备；
- 网关已超过子设备负载量。

### Aqara门窗传感器 T1 为什么会经常离线？

可能的原因：

- 设备与网关距离较远，请验证传感器与网关间的距离，将设备安装在靠近网关的位置；
- 电池电量低或电池没电，请更换新电池；
- 传感器安装在金属表面，无线信号受到干扰。

### 如何判断 Aqara门窗传感器 T1 是否工作正常？

- 单击门窗传感器主体的重置按键，网关发出提示音“连接正常”，则表示传感器与网关通讯正常，请看下一步骤；如无提示，请将传感器移近网关后重试，若还是无提示音，则传感器可能已经被删除或电池已耗尽，请参照本说明书「设备入网」章节重新添加设备或更换新电池；
- 将传感器主体与磁铁靠近及分离2~3次，然后进入 Aqara Life App 或 Aqara Studio 网页端中门窗传感器 T1 的设备主页面，如有状态变化，则表明设备工作正常。

### Aqara门窗传感器 T1 有哪些功能？

- Aqara门窗传感器 T1 可以安装在门或窗上，实时感知门或窗的开关状态；
- 与其他智能设备搭配使用，当感应到门窗的打开或关闭时，联动控制设备的开关或其他动作。

### Aqara门窗传感器 T1 有时工作，有时不工作？

- 传感器主体与磁铁间的距离可能过大。请检查传感器主体与磁铁间的距离，两者的距离不能大于22mm；
- 传感器与网关之间的距离可能过长。确定传感器主体与磁铁间的距离在22mm以内后，在传感器的安装位置单击传感器的重置按键，如果网关发出提示音，则表示在该安装位置传感器可以和网关有效通讯，否则请将传感器移近网关。

### 如何重置 Aqara门窗传感器 T1？什么情况下重置？

- 长按5秒设备的重置按键，指示灯闪烁3次，恢复出厂设置；
- 在已绑定的传感器重新绑定到另一个网关的情况下，需要先重置传感器，才能让传感器与新网关绑定成功。
