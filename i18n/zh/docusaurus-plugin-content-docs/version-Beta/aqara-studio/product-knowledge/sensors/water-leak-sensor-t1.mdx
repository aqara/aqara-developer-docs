# 水浸传感器 T1

## 产品介绍

Aqara水浸传感器 T1是一款基于 Zigbee 3.0 无线通信协议的可以检测无水到有水、有水到退水两种状态的传感器。Aqara水浸传感器 T1可以根据检测漏水做为自动化条件，联动网关或其他设备执行多种智能场景。

## 部件说明

| 部件 | 说明 |
| -- | -- |
| 指示灯 | 设备状态指示 |
| 重置键 | 长按5s：重置/入网；单击：有效通讯距离验证/设备查找功能 |
| 感应探头 | 浸水/漏水检测 |

:::tip
传感器天线位于“水滴”图标上方。
:::

## 安装方法

有效距离验证：在预选的安装位置，单击设备重置键，网关发出提示音，表明设备与网关之间可以有效通讯。

:::tip
为了确保无线通信稳定，请避免安装在金属表面。
:::

### 方式一

直接放置在所需位置。

### 方式二

用内六角螺丝刀将感应探头拧松，接上导线后，可应用于更多场景。

## 设备入网

请依照网关说明书，通过 Aqara Life App 或 Aqara Studio 网页端完成网关添加。

:::tip
- 请确保添加过程中设备处于配网模式（指示灯闪烁状态），如指示灯处于其他状态，可按住重置键 5 秒钟直到 LED 指示灯开始闪烁，然后释放，设备将再次进入入网配对模式。
- 固件升级：为保证最佳使用体验，请在设备完成添加后，先在 Aqara Life App 或 Aqara Studio 网页端的设备设置页更新设备固件到最新版本后开始使用。
- 如添加失败，请将设备移近网关后重试。如需帮助请查询：www.aqara.com/support。
:::

### 通过 Aqara Life App 添加

请在 Aqara 官网或 Apple App Store / Google Play 应用商城搜索并下载最新版本的 Aqara Life App。通过 App 指引的“添加设备”流程，扫瞄本产品产品包装或说明书印刷版上的 Zigbee 3.0 Install Code，完成设备添加。

### 通过 Aqara Studio 网页端添加

请在 Aqara Studio 网页端平台登录后，按照网页端指引完成设备添加。

## 常见问题

### Aqara水浸传感器为什么会经常离线？

可能的原因：
- 设备与网关距离较远，请验证传感器与网关间的距离，将设备安装在靠近网关的位置；
- 电池电量低或电池没电，请更换新电池；
- 设备安装在金属表面，信号受到干扰。

### Aqara水浸传感器连接失败的原因是什么？应该如何重新连接？

可能的原因：
- 操作错误，请重新根据设备添加方式，重新添加设备；
- 距离网关过远，将设备移近网关后重新添加设备；
- 网关的子设备负载量超额。

### Aqara水浸传感器有什么功能？

Aqara水浸传感器是一款可检测漏水和浸水的设备，能够监测无水到有水、有水到退水两种状态，当发生漏水或浸水时可通过 App 实时推送报警信息，并能够通过网关设备联动控制其他智能硬件产品。

### Aqara水浸传感器的工作原理是怎样的？

Aqara水浸传感器利用水的导电性，当两个探针同时接触到水时，形成电流回路，此时传感器上报浸水/漏水状态给网关，从而触发报警，或联动其他智能设备执行相关动作。

### Aqara水浸传感器与网关之间是通过什么进行通信的？

Aqara水浸传感器与网关之间通过无线Zigbee协议进行通信，无需布线。Zigbee技术是一种短距离、低功耗的无线通信技术，是近几年流行起来的智能家居控制系统的通讯协议，它对比其他通讯协议有以下几点优势：
- 超低功耗；
- 安全性高；
- 自组网，可容纳子设备多。

### Aqara水浸传感器能否单独使用？
 
不能。Aqara水浸传感器必须搭配网关类设备才能使用，网关设备实现Zigbee与Wi-Fi信号的转换。

### Aqara水浸传感器的安装有什么要求？

Aqara水浸传感器的安装简单方便，直接放置在所需监测的平面上即可。

### 水位达到多少时才能触发报警？

当检测的水位达到0.5mm高度时，即可触发报警。

### Aqara水浸传感器的按键在哪里？

Aqara水浸传感器的按键设计在面壳的中部，手指捏住上壳与底盖，并用力按压“水滴”图标位置即可触发按键。

### Aqara水浸传感器的供电方式是什么？

Aqara水浸传感器采用CR2032的锂金属纽扣电池，输出电压为3V，正常情况下可工作约两年（实际使用时长视具体情况而定）。
