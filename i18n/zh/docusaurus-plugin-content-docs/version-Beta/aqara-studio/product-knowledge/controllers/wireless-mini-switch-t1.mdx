# 无线开关 T1

## 产品介绍

Aqara 无线开关 T1 是一款新型无线遥控开关，支持单击、双击、长按三种控制方式，可以任意放置在需要的位置或粘贴安装使用，与网关联动并搭配其他智能设备执行丰富的智能场景。

| 部件 | 说明 |
| -- | -- |
| 重置键 | 长按 5s：重置/入网；单击：有效通讯距离验证/设备查找功能 |
| 按键 | 按键 |
| 指示灯 | 指示灯 |

## 设备入网

### 通过 Aqara Life App 添加

请在 Aqara 官网或 Apple App Store / Google Play 应用商城搜索并下载最新版本的 Aqara Life App。通过 App 指引的“添加设备”流程完成设备添加。

### 通过 Aqara Studio 网页端添加

请在 Aqara Studio 网页端平台登录后，按照网页端指引完成设备添加。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/wireless-mini-switch-t1-image2.png" alt="通过 Aqara Studio 网页端或 Aqara Life App 添加设备"  style={{ width: '70%' }} />

:::tip
- 请确保添加过程中设备处于配网模式（指示灯呼吸状态），如指示灯处于其他状态，可按住重置键 5 秒钟直到 LED 指示灯开始闪烁，然后释放，设备将再次进入入网配对模式。
- 固件升级：为保证最佳使用体验，请在设备完成添加后，先在 APP 里设置页里更新设备固件到最新版本后开始使用。
- 如添加失败，请将设备移近网关后重试。
:::

## 固件升级

为保证最佳使用体验，请在设备完成添加后，先在 APP 里设置页更新设备固件到最新版本后开始使用。

:::tip
第三方生态如无法获取到最新固件，用户可通过在 Aqara Life 中添加设备，进行两次“协议切换”操作（如将 Thread 切换为 Zigbee 再重新切换为 Thread），拉取到云端最新固件并进行升级。
:::

## 协议切换

如果在设备使用过程中需要切换协议，可以在 Aqara Life App 中先移除设备，然后长按设备重置键 5 秒钟将设备重置，进入配对过程，在设备配对屏幕上点击“切换协议”并选择所需的协议，按照应用程序的说明完成设置。

:::tip
切换协议将会清除设备的所有设置和数据，如需保留配置后续使用，请先记录当前配置。
:::

## 安装方法

有效距离验证：在预选的安装位置，单击设备重置键，网关发出提示音，表明设备与网关之间可以有效通讯。

:::tip
为了确保无线通信稳定，请避免安装在金属表面。
:::

### 方式一

直接放置在所需位置。
