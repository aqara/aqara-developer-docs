## 产品概述

边端盒子 GX500M 是一款工规级 RK3588J 无风扇嵌入式工控主机，内置 Aqara Studio 跨协议管理应用，面向 B 端项目，适用于大型楼宇、商业建筑、智慧工厂等中大型项目的多协议接入与集中管理。产品具备较强算力与丰富接口，支持通过本地局域网访问，并可经 Aqara IoT 云端实现互联网远程代理访问，助力构建灵活、安全、高效的智能空间系统。

:::note
本产品为 Aqara Studio 边缘主机（主机角色，非子网关），采用有线方式入网，不支持 Aqara Home APP。
:::

## 安装说明

### 安装条件确认

支持标准桌面式安装、书本式壁挂安装、DIN 导轨安装、VESA 挂架安装；随机附 DIN 导轨安装配件。

### 安装注意事项

- 请使用随附的 12V⎓5A 电源适配器供电；
- 安装、接线前请确认设备已断电；
- 请勿在潮湿、高温或强电磁干扰环境中使用；
- 保持机身散热面通风，请勿遮挡。

## 使用说明

### 快速设置

#### 1.供电

使用 12V⎓5A 电源适配器连接设备 DC-IN 接口。

#### 2.联网（有线）

本产品为Aqara Studio一体机，需要连接HDMI显示器、鼠标、键盘及网线使用

#### 3.访问 Aqara Studio

开机自动打开Aqara Studio

#### 4.接入设备

在 Aqara Studio 中按协议接入和管理设备（具体支持协议以 Studio 兼容清单及插件授权为准）。

#### 5.扩展（可选）

可安装 NVMe SSD、4G/5G 模块等扩展，详见供应商规格书。

## 产品功能

### 主要能力

1. Aqara Studio 边缘主机：内置 Studio，支持本地部署与跨协议管理；
2. 多协议接口：2× RJ45 千兆、4× RS-485、2× RS-232、GPIO、Wi-Fi 5、蓝牙 5.2、4G/5G（可选）；

## 排障指引

### 故障现象及可能的原因与解决方案

常见无法访问 Studio：

- 确认设备与访问终端处于同一局域网；
- 通过机身默认管理地址或路由器分配的 IP 访问；
- 检查网线与交换机状态；
- 跨 VLAN 时 mDNS 可能失效，可改用静态 IP 访问。
