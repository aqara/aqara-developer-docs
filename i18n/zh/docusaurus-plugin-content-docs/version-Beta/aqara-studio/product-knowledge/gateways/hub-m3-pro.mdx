## 产品概述

方舟智慧中枢 M3 Pro 是 Aqara 面向 Aqara Studio 推出的中枢网关（内部代号「M3 Studio版」），与消费级「智慧家庭中枢 M3 / Hub M3」为两款不同产品。M3 Pro 支持 Thread 边界路由、Zigbee 3.0 与蓝牙多模接入，可作为 Matter Controller 和 Thread Border Router。采用 ARM 双核 A7 主控，主频 1GHz；支持 2.4GHz / 5GHz 双频 Wi-Fi 及 RJ45 有线联网（支持 PoE 受电）。内置 eMMC 本地存储与 RTC 时钟系统，断网仍可稳定校时；配备 6 发 1 收增强版红外遥控与扬声器，支持平放、壁挂和吸顶三种安装方式，支持网关替换与本地自动化。

:::note
本产品面向 Aqara Studio 平台，不支持配网到 Aqara Home APP
:::

## 安装说明

### 安装条件确认

支持室内平放、壁装和吸顶三种安装方式；壁装/吸顶需使用随附支架与螺丝包。

### 安装注意事项

- 请在断电状态下接线，避免发生电气事故；
- 使用 PoE 供电时，请确认交换机/供电设备支持 IEEE 802.3af；
- 使用电源适配器供电时，请使用 5V⎓2A 适配器并搭配随附 Type-C 供电线；
- 本产品仅限室内使用，请勿在潮湿环境或室外使用。

## 使用说明

### 快速设置

#### 1.供电

可通过 Type-C（5V⎓2A）供电，或通过 RJ45 网口 PoE 受电。

#### 2.安装

按场景选择平放、壁挂或吸顶安装。

#### 3.等待启动

网关指示灯点亮并进入等待配网状态。

#### 4.配网

本产品面向 Aqara Studio，支持有线与无线两种入网方式：

- 有线：接入局域网后，通过 Studio 管理页面配网；
- 无线：通过 Aqara Life APP 完成无线网络配置。

不支持配网到 Aqara Home APP。详见 Aqara Studio 入网指引。

#### 5.接入 Aqara Studio

在 Aqara Studio 的「设备管理 → Aqara Hub」中点击「发现设备」，在局域网内搜索并添加本网关。

#### 6.绑定子设备

绑定 Zigbee 设备、Thread 设备、蓝牙设备、红外设备：详见对应入网指引。

#### 7.恢复网络参数 / 恢复出厂设置

按键操作详见「产品功能」中的按键说明。

## 产品功能

### 主要能力

1. 家庭中枢：支持跨局域网、跨网关的本地自动化执行和多中枢集群组网；
2. 支持 Matter：可作为 Thread Border Router 和 Matter Controller；
3. 多模网关：支持 Thread、Zigbee、蓝牙（BLE）、红外 RF、以太网等多种协议设备接入 Aqara Studio；
4. 网关替换：支持 M3 Pro 之间的替换，以及 M3 Pro替换 M100 Pro、M200 Pro 和 AX200M ；
5. 本地存储：内置 eMMC，用户数据本地化存储，降低云端依赖；
6. 万能红外遥控：6 发 1 收，支持红外发射与学习；
7. 离线校时：内置 RTC 时钟系统，断网仍可维持设备校时；
8. 自定义铃声：支持上传自定义铃声，实现语音播报联动；
9. PoE 供电：通过 RJ45 网口实现 PoE 受电，减少布线；
10. Type-C 通信：除供电外还可扩展 4G/5G 网卡等外设进行数据通信；
11. 双频 Wi-Fi：2.4GHz / 5GHz，IEEE 802.11 a/b/g/n/ac。

### 接口说明

## 排障指引

### 故障现象及可能的原因与解决方案

常见入网失败：

- 请通电后长按网关按键 10 秒以上，待指示灯进入配网状态后，重试添加；
- 检查路由器是否开启 Wi-Fi 防蹭设置，导致网关无法正常联网；
- 检查路由器是否开启 AP 隔离，导致局域网内无法搜索到网关；
- 使用 PoE 供电时，确认交换机支持 IEEE 802.3af；
- 建议不要连接桥接网络。

## 常见问题 FAQ

### 方舟智慧中枢 M3 Pro 常见问题

### 是否支持 Aqara Home APP？

不支持。M3 Pro 面向 Aqara Studio 平台，不支持配网到 Aqara Home APP，也不含 HomeKit 生态。

### 与智慧家庭中枢 M3 是什么关系？

两者是两款不同产品。M3 为消费级产品，M3 Pro 为面向 Aqara Studio 的版本（内部代号「M3 Studio版」）。

### 方舟智慧中枢 M3 Pro 是否支持 PoE 供电？**  

支持。可通过 RJ45 网口实现 IEEE 802.3af PoE 受电（48V⎓0.27A）。
