## 产品概述

网关 M100 Pro 是 Aqara 面向 Aqara Studio 推出的一款高性价比 Matter 网关，可接入 Aqara Studio 平台。支持同时接入 Zigbee 和 Thread 子设备，可作为 Thread Border Router、Matter Controller 使用。主控采用 ARM 双核 A7 架构，工作主频 1GHz，支持 2.4GHz Wi-Fi 6 无线连接。产品体积小巧、安装灵活，可从带有标准 USB-A 接口的插座、电器等产品上取电使用，并可接入第三方 Matter 生态。

:::note
本产品无网口，不支持有线入网，仅支持无线（Wi-Fi）连接；不支持配网到 Aqara Home APP，需要搭配 Aqara Life APP 使用
:::

## 安装说明

### 安装条件确认

安装工具：无需额外工具，通过机身 USB-A 接口插入带标准 USB-A 口的电源（插座/电器/5V⎓0.5A 电源适配器）即可供电。

### 安装注意事项

- 请使用符合要求的 5V⎓0.5A 电源供电，避免使用输出不达标的电源适配器；
- 本产品无网口，仅支持无线（Wi-Fi）联网；
- 本产品仅限室内使用，请勿在潮湿环境或室外使用；
- 请勿遮挡机身或损坏 USB-A 接口。

## 使用说明

### 快速设置

#### 1.供电

将网关插入带标准 USB-A 接口的电源（插座、电器或 5V⎓0.5A 电源适配器）。

#### 2.等待启动

网关指示灯点亮并进入等待配网状态（指示灯状态说明详见「产品功能」）。

#### 3.配网（无线）

本产品无网口，不支持有线入网，仅支持无线（Wi-Fi）连接。初次配网通过 Aqara Life APP 完成无线网络配置，配网成功后接入 Aqara Studio（不支持配网到 Aqara Home APP）。详见 Aqara Studio 入网指引。

#### 4.接入 Aqara Studio

在 Aqara Studio 的「设备管理 → Aqara Hub」中点击「发现设备」，在局域网内搜索并添加本网关。

#### 5.绑定子设备

- 绑定 Zigbee 设备：详见 Zigbee 设备入网指引；
- 绑定 Thread 设备：详见 Thread 设备入网指引。

#### 6.恢复网络参数 / 恢复出厂设置

按键操作详见「产品功能」中的按键说明。

## 产品功能

### 主要能力

1. 可作为 Matter 网关使用：Thread Border Router + Matter Controller；
2. 多模网关：支持将 Thread 设备、Zigbee 设备接入 Aqara Studio 及第三方 Matter 生态；
3. 网关替换：支持 M100 Pro 之间的替换，也支持 M3 Pro、M200 Pro、AX200M 替换 M100 Pro，增强容灾备灾能力；
4. 本地自动化：支持 Aqara Studio 创建的自动化下沉到网关执行，断网可执行；
5. 通用 USB-A 接口供电，安装和使用灵活；
6. 2.4GHz Wi-Fi 6 无线连接，支持 IEEE 802.11 b/g/n/ax。

### 接口说明

| 接口名称 | 功能说明 |
| -- | -- |
| USB-A 接口 | 供电接口，用于连接带标准 USB-A 口的电源 |
| 按键 | 1 个实体按键，用于恢复出厂设置、子设备添加、消除报警等 |
| 指示灯 | 1 个 RGB 指示灯，用于显示设备工作状态 |

### 按键说明

| 操作方式 | 功能说明 |
| -- | -- |
| 快按功能键 3 次 | 进入添加 Zigbee 子设备状态 |
| 长按功能键 10 秒以上 | 恢复网络参数（用户配置数据不发生改变） |
| 快按功能键 10 次 | 恢复出厂设置（清除所有用户数据至出厂状态） |

### 指示灯说明

RGB 指示灯用于指示设备工作状态（具体灯色/闪烁含义以正式说明书为准，待补充）。

## 排障指引

### 故障现象及可能的原因与解决方案

常见入网失败：

- 请通电后长按网关按键 10 秒以上，待指示灯进入配网状态后，重试添加；
- 检查路由器是否开启 Wi-Fi 防蹭设置，导致网关无法正常联网；
- 检查路由器是否开启 AP 隔离，导致局域网内无法搜索到网关；
- 建议不要连接桥接网络。
