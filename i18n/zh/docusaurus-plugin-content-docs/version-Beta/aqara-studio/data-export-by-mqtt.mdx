# 以 MQTT 转出设备数据

您可以通过 Aqara Studio 内置的 MQTT broker，或集成您自有的 MQTT broker，将设备数据便捷地转发至第三方平台，实现对已接入设备的查询与控制。

:::tip
本文将以 MQTTX 桌面端应用为例，详细讲解如何建立 MQTT 连接，并进行消息的订阅与发布。
:::

## 您可以通过 MQTT 转出实现哪些功能？

通过 MQTT 转出功能，您可以借助 MQTT Broker，以发布/订阅方式发送请求消息，调用已开放的数据转出 HTTP API。此外，您还可以实现心跳保活、订阅或取消订阅设备数据，以及接收设备数据变化和其他对象事件。

上述功能的请求体与响应体的 JSON 对象说明，请参考 Aqara Developer [Studio 本地开发 - MQTT](./../aqara-developer/data-export-api/mqtt-api/mqtt-api.mdx)。

## 安装插件

请参考 [插件市场](./plugin-center.mdx) 文档：
1. 前往 [Aqara Builder 工坊 - 市场](https://builder.aqara.com/lab/plugin-store) 获取 `MQTT Export` 插件。
2. 将其分配到 Aqara Studio。
3. 并前往 Aqara Studio 的 **插件中心** 安装 `MQTT Export` 插件。

## 启用 MQTT 转出服务

1. 在 Aqara Studio 左侧侧边栏进入 **插件中心**，找到 `MQTT Export` 插件，点击 **转出**。

    ![在插件中心找到 MQTT Export 插件，点击转出](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/MQTT-ClickTransferOut.png) 

2. 页面会跳转至 **开发者** 页面，请 **启用MQTT转出** 服务。

    ![启用 MQTT 转出服务](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/MQTT-EnableMQTTTransferOut.png) 

## 选择 Broker

根据您的实际需求选择合适的 Broker：
- 如果您没有自建的 MQTT Broker，可直接 [使用 Aqara Studio 内置的本地 Broker](#使用本地-broker)。
- 如果您不想使用 Aqara Studio 的内置 Broker，可选择 [使用第三方 Broker](#使用第三方-broker)。

### 使用本地 Broker

如需使用 Aqara Studio 内置的本地 Broker，请选择 **本地 Broker**。

此时，Aqara Studio 默认连接该 Broker。

![使用本地 Broker](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/MQTTExport-SelectLocalBroker.png) 

如果连接状态为 **未连接**，您可以选择 **... > 连接** 来手动连接。

![手动连接](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/MQTTExport-ConnectToLocalBroker.png) 

### 使用第三方 Broker

如需使用第三方 MQTT Broker，步骤如下：
1. 选择 **第三方 Broker**，填写如下信息：

    | 名称       | 说明                         |
    |----------|----------------------------|
    | HOST       | 第三方 MQTT Broker 的地址。              |
    | 端口     | 第三方 MQTT Broker 的端口号。            |
    | 客户端 ID | Aqara Studio 用于连接该 Broker 的客户端**唯一**标识。         |
    | 用户名    | 连接第三方 MQTT Broker 时所需的用户名。            |
    | 密码     | 连接第三方 MQTT Broker 时所需的密码。              |
    | 启用 TLS | 是否启用 TLS 加密传输。<ul><li>开启：MQTT Broker 地址需使用 MQTTS 协议；</li><li>关闭：使用 MQTT 协议。</li></ul> |

    ![选择第三方 Broker](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/MQTTExport-SelectThirdPartyBroker.png) 

2. （**若已启用 TLS**）根据您希望实现单向认证，或是双向认证，您需要提供的如下内容：

3. 点击 *...* 按钮，呼出操作菜单，选择 **连接**，等待连接成功。

    ![连接第三方 Broker](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/MQTTExport-ConnectToThirdPartyBroker.png) 

## 测试 MQTT Broker 连接

:::tip
- 开始测试前，请先下载并安装 [MQTTX](https://mqttx.app/zh/downloads) 桌面端应用，或其他同类 MQTT 客户端工具。
- 下列步骤以 MQTTX 为例，其他 MQTT 客户端工具的使用方法请阅读其官方文档。
:::

1. 从上述 Aqara Studio 的 **开发者** 页面中获取 MQTT 连接所需的所有信息（如 HOST、端口、用户名、密码），以及请求和响应 Topic 的格式。

    下图以使用本地 Broker 为例：

    ![获取 MQTT 连接所需信息](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/MQTTExport-FindInfo.png) 

2. 参考 MQTTX 官方文档 [开始使用 - 快速建立连接](https://mqttx.app/zh/docs/get-started#%E5%BF%AB%E9%80%9F%E5%BB%BA%E7%AB%8B%E8%BF%9E%E6%8E%A5)，使用上述获取的信息，建立 MQTT 连接。

    ![建立 MQTT 连接](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/mqtt-export-2.png) 

3. 连接成功后，点击 **New Subscription** 按钮。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/MQTTX-NewSubscription.png" alt="新建订阅" style={{width: '60%'}} /> 

    根据 Aqara Studio 显示的 **响应 Topic 格式**，将其中的 ClientID 替换为 MQTTX 自动生成的实际 ClientID，以完成对响应消息的订阅。

    选择 QoS 为 1，单击 **Confirm** 按钮，以创建订阅。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/mqtt-export-3.png" alt="订阅响应" style={{width: '60%'}} /> 

4. 在已创建的订阅中，将 Aqara Studio 提供的 **请求 Topic 格式**中的 ClientID 替换为 MQTTX 自动生成的实际 ClientID，并填写到 Topic 输入框。
    
    参照 Aqara Developer [Studio 本地开发 - MQTT](./../aqara-developer/data-export-api/mqtt-api/mqtt-api.mdx) 中各接口的请求参数说明，编写 JSON 格式的消息并发送，即可获得响应。

    下图以 [订阅全部设备数据](./../aqara-developer/data-export-api/mqtt-api/mqtt-api.mdx#订阅全部或指定设备) 的请求为例：

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/mqtt-export-4.png" alt="发送请求" style={{width: '70%'}} /> 

    以下为响应示意图：

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/mqtt-export-5.png" alt="收到响应" style={{width: '70%'}} />
