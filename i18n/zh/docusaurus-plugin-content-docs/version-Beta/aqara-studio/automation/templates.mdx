# 模板

Aqara Studio 支持您将已有的自动化或场景 [转换为模板](#生成模板)，以便您之后可以 [重复使用该模板为新自动化或场景的基础](#使用模板创建自动化或场景)。

除此之外，您也可以 [将其导出](#导出模板)，用于本地存档或 [导入](#导入模板) 到其他 Aqara Studio。

## 生成模板

将自动化或场景转换为模板的操作步骤如下：
1. 在自动化列表或场景列表中，找到您想要转换的一项，单击 **... > 生成模板**。

    ![转换为模板](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Template-GenerateTemplate.png)

2. 在弹窗中输入模板名称。Aqara Studio 会默认生成一段描述，您也可以按需修改，以进一步说明该模板的作用。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Flow-DefineTemplateNameAndDescription.png" alt="定义模板名称和描述" style={{width: '50%'}} />

3. 当页面提示模版生成成功或类似文案时，即表示自动化或场景已成功转换为模板。切换至 **模板管理** 标签页，即可在列表中看到刚转换的模板。

    ![模板列表](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Flow-TemplateList.png)


## 使用模板创建自动化或场景

使用模板创建自动化或场景，可让您基于已有的模板，快速创建新的自动化或场景。

流程如下：
1. 在模板列表中，找到要使用的模板，单击 **... > 使用模板创建**，即可进入新创建的自动化或场景编辑页面。
    
    ![使用模板创建自动化](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Flow-UseTemplateToCreate.png)

2. 此时返回 **自动化** 或 **场景** 标签页，你可以看到自动化或场景列表中新增一条自动化或场景。

    ![检查新自动化](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Flow-CheckNewFlow.png)

## 导出模板

在模板列表中，找到您想要导出的模板，单击 **... > 导出**，即可开始以 JSON 格式将模板下载至本地。

![导出模板](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Flow-ExportTemplate.png)

## 导入模板

如果您希望将本地的自动化模板 JSON 文件导入至 Aqara Studio，在 **模板管理** 标签页中单击 **导入** 按钮，即可开始导入。

![导入模板](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Flow-ImportATemplate.png)
