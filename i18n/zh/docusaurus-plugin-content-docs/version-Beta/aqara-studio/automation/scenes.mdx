# 场景

场景用于保存多个 [执行](./../flow/action.mdx) 卡片，并在激活时同时触发这些动作。例如，“回家模式”场景可以开灯并调节空调至舒适温度。

## 什么时候使用场景？

当多组设备动作需要一并执行，且您希望在多处重复调用时，请使用场景。

例如，可将开灯、调空调等动作保存为「回家模式」：既可用无线开关手动触发，也可在门锁开锁后由自动化自动执行，无需重复配置同一组动作。

若这些动作只在某一条自动化中使用一次，则不必单独保存为场景，直接在该自动化中添加对应的 [执行](./../flow/action.mdx) 卡片即可。

## 创建场景

在左侧导航栏单击 **自动化** 标签。在 **场景** 标签下单击 **创建** 按钮。

![单击创建按钮](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Scene-Create.png)
