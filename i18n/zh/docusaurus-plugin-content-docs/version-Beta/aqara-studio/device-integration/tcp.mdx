# TCP 设备接入

本文将指导您如何通过编写 JS 脚本，将 TCP 协议设备接入 Aqara Studio 以及将设备功能点按照 **Aqara 物模型规范** 完成映射，实现设备的发现、添加及功能点控制等操作。

## 经测试的 TCP 设备

以下列出经 Aqara 测试可正常接入 Aqara Studio 的 TCP 设备：
- 向往音响
- JBL 音响
- Kudi 播放器

## 学习并编写 JavaScript 脚本

脚本结构与配置流程，参见 [第三方设备脚本接入指南](../ai-agent-device-onboarding.mdx)。

请参考 [JavaScript 脚本（适用于 UDP 和 TCP）](./../unified-protocol-script.mdx#tcp-udp) 的编写方法，编写符合 **Aqara 物模型规范** 的 JavaScript 脚本。此脚本将用于指导 Aqara Studio 如何发现设备、添加与控制功能点等。

## 安装插件

请参考 [插件市场](./../plugin-center.mdx) 文档：
1. 前往 [Aqara Builder 工坊 - 市场](https://builder.aqara.com/lab/plugin-store) 获取 `TCP Protocol Access` 插件。
2. 将其分配到 Aqara Studio。
3. 并前往 Aqara Studio 的 **插件中心** 安装该插件。

## 添加 TCP 设备

1. 在左侧侧边栏点击进入**设备管理**页面。在左侧 **协议和设备** 单击 **...** 按钮，选择 **添加协议**。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Devices-AddProtocol.png" alt="添加协议" /> 

2. 在弹窗中选择 `TCP`，以添加一个 TCP 节点。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Devices-SelectTCP.png" alt="添加 TCP" style={{width: '70%'}} /> 

3. 选择该节点，进入管理界面。点击 **协议配置** 按钮。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-ProtocolConfiguration.png" alt="协议配置" /> 

4. 在弹窗中单击 **脚本配置** 按钮。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-ScriptConfiguration.png" alt="脚本配置" style={{width: '60%'}} /> 

5. 将 [编写好的 JavaScript 脚本](#学习并编写-javascript-脚本) 粘贴到代码框中，确保 TCP 设备及其功能点能被 Aqara Studio 正确识别和管理。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-ScriptEditor.png" alt="代码粘贴至脚本编辑器" style={{width: '60%'}} /> 

6. （可选）如果您希望用 `msgId` 来匹配发送消息与接收消息，请启用 `Match by msgId` 开关。若无启用，则表示按顺序处理。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-MsgIdMatch.png" alt="消息 ID 匹配" style={{width: '60%'}} /> 

7. 返回 TCP 管理页面，单击 **添加设备** 按钮。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-AddDevice.png" alt="单击添加设备按钮" /> 

8. 在弹窗中选择 **自动发现** 作为接入方式，并选择 **开始接入设备** 进入下一步。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-SelectAutoDiscovery.png" alt="选择自动发现作为接入方式" style={{width: '60%'}} /> 

9. （可选）单击 ⚙ 图标。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-Gear.png" alt="单击齿轮图标" /> 

    若您的 TCP 设备是通过 TCP 协议被发现，请选择 **TCP** 选项；若您的 TCP 设备是通过 UDP 协议被发现，请选择 **UDP** 选项。

    :::tip
    固定发现目标可由 [describe().discovery](../unified-protocol-script.mdx#tcp-udp-discovery) 提供，或在允许编辑时填写弹窗。encode(discoverDevices) 构造请求，decode 返回带真实设备地址的 devices 候选；仅写一份地址清单不等于完成设备发现。没有发现协议时使用当前公开的手工创建入口。
    :::

    - **TCP**：   
        在弹窗内填写 TCP 目标的 IP 地址和端口号，或使用脚本提供的发现配置。该目标通过 [encode(discoverDevices)](../unified-protocol-script.mdx#tcp-udp-discovery) 组包并发送，decode 解析设备响应形成候选。
        <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-TCPIPConfiguration.png" alt="配置服务端 IP 地址和 Port" style={{width: '50%'}} />

    - **UDP**：   
        设置 `Discovery Type` 为 `UDP`。   
        <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-DiscoveryType.png" alt="配置发现类型" style={{width: '50%'}} />   
        配置实际 UDP 广播/组播目标，或由 describe().discovery 提供；[encode(discoverDevices)](../unified-protocol-script.mdx#tcp-udp-discovery) 发送后由 decode 解析回复中的设备身份和 TCP 地址。厂商要求固定回复端口时另配 responseIp/responsePort。
        <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-IPConfiguration.png" alt="配置服务端 IP 地址和 Port" style={{width: '50%'}} />

10. 选择 **发现设备** 按钮。

    Aqara Studio 会根据您编写的 [JS 脚本](#学习并编写-javascript-脚本) 自动扫描并识别可接入的 TCP 设备，被发现的设备会在**发现设备列表**中展示。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-DiscoverDevices.png" alt="发现设备" /> 

11. 选择需接入的设备，点击中间“+”按钮。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-AddDiscoveredDevices.png" alt="新增发现设备" /> 

    新增设备会出现在右侧的已添加设备列表。单击 **完成** 按钮，退出添加设备流程。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-AddedDeviceList.png" alt="已添加设备列表" /> 


12. 此时，您将在左侧 **协议和设备** 的 TCP 节点下，以及该 TCP 管理页面的设备列表中，看到已成功添加的设备。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-CheckAddedDevices.png" alt="设备已添加至 TCP 下" /> 

## 添加功能点

1. 在 TCP 节点下选择一个 TCP 设备，单击 **添加功能点** 按钮。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-SelectDeviceAndAddPoint.png" alt="选择设备并添加功能点" /> 

2. 选择 **发现功能点** 按钮。

    :::tip
    - 远端点表：encode(discoverPoints) 返回请求字节，decode 从真实响应返回 [pointDefinitions](../unified-protocol-script.mdx#point-definitions)。
    - 静态点表：encode(discoverPoints) 返回 null，decode 收到 bytes=null 后返回 pointDefinitions，不发查询。
    两种方式都需要选择并导入点。设备运行时选项变化另用 [动态枚举](../unified-protocol-script.mdx#dynamic-enums)，不是每次重新创建点。
    :::

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-DiscoverPoints.png" alt="发现功能点" /> 

3. 在 **发现功能点列表** 勾选需要的点，单击中间 **+** 按钮。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-AddDiscoveredPoints.png" alt="新增发现功能点" />
    
    新增功能点会出现在右侧的 **已添加功能点** 列表。单击 **完成** 按钮，退出添加功能点流程。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-AddedPoints.png" alt="已添加功能点" /> 

4. 此时，您将在该 TCP 设备的管理页面中，看到已成功添加的功能点。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/TCP-CheckPoints.png" alt="已添加功能点" />
