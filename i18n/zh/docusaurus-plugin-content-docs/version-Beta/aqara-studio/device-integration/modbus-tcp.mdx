# Modbus TCP 设备接入

本文说明如何将 Modbus TCP 设备接入 Aqara Studio。

## 支持的 Modbus TCP 点位数据类型

在将您的 Modbus TCP 设备接入 Aqara Studio 时，请确保其点类型在 Aqara Studio 支持的范围内（如下表所列）：

| 类型 | 范围 | 寄存器数 |
|----|----|----| 
| UInt16 | 0～65,535 | 1 |
| Int16 | −32,768～32,767 | 1 |
| Int32 | −2,147,483,648～2,147,483,647 | 2 |
| UInt32 | 0～4,294,967,295 | 2 |
| Float32 | IEEE 754 单精度 | 2 |
| Boolean | 线圈、离散输入 | 1 bit |
| RegisterBit | 单寄存器的 bit0～15 | 单寄存器内 |
| NumericBits / EnumBits | 单寄存器内的无符号位段 | 单寄存器内 |
| 普通 String | 保持寄存器字节按 UTF-8 解码，当前只读 | 按长度 |

## 经测试的 Modbus TCP 设备

以下列出经 Aqara 测试可正常接入 Aqara Studio 的 Modbus TCP 设备：

| 品牌 | 型号 |
|----|----|
| Siemens | LOGO |
| Siemens | S7-200 SMART CPU SR20 |
| 浙江正泰电器 | CHNT DDSU6665(80) |
| 杭州塔石物联 | TAS-LAN-464 |
| 埃美柯 | LXLY-50 |

## 前提条件

在开始之前，请确保：
- 您的 Modbus TCP 设备、Aqara 网关和电脑处于同一局域网中。
- 您的 Modbus TCP 设备已完成 Modbus TCP 相关配置。如何配置，请参考产品说明书或咨询设备厂商技术支持。

## 添加 Modbus TCP 设备

1. 在左侧侧边栏点击进入**设备管理**页面。在左侧 **协议和设备** 单击 **...** 按钮，选择 **添加协议**。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Devices-AddProtocol.png" alt="添加协议" /> 

2. 在弹窗中选择 `Modbus TCP`，以添加 `Modbus TCP`。   
    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Protocols-ChooseModbusTCP.png" alt="选择 Modbus TCP" style={{ width: '60%' }} /> 

3. （可选）在左侧 **协议和设备** 树选择新增的 **Modbus TCP** 节点，选择 **协议配置** 按钮，即可设置高级配置。配置完成后即可关闭此弹窗：    
    
    ![单击协议配置按钮](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/ModbusTCP-ClickProtocolConfiguration.png)

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/ModbusTCP-AdvancedConfiguration.png" alt="高级配置" style={{ width: '70%' }} />

    | 参数名称 | 说明 |
    | --- | --- |
    |启用/禁用该设备 | 注意：禁用后该设备将不可用。|
    |浮点数字节序 | 32 位浮点数的读写顺序，支持如下：<ul><li>Order BADC</li><li>Order ABCD（默认）</li><li>Order CDAB</li><li>Order DCBA</li></ul>|
    |长整型字节序 | 32 位 Int32/UInt32，占两个连续寄存器，支持如下：<ul><li>Order BADC</li><li>Order ABCD（默认）</li><li>Order CDAB</li><li>Order DCBA</li></ul>|

4. 单击**添加设备**按钮，进入添加流程。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/ModbusTCP-ClickAddDevice.png" alt="单击添加设备按钮" />

5. 在步骤 1 中配置目标 Modbus TCP 设备的设备配置和高级配置。完成后，单击**下一步**按钮。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/ModbusTCP-AddDeviceStep1.png" alt="添加设备步骤 1" />

  - 设备配置：   
    | 参数名称 | 是否必填 | 说明 |
    | --- | --- | --- |
    | 设备名称 | ✔ | 您自定义的设备名称。  |
    | 设备地址 | ✘ | 此设备从站地址（单位标识符），范围 0~255。 |
    | IP 地址 | ✔ | 此设备的 IP 地址。 |
    | 端口 | ✔ | Modbus TCP 通信端口，默认 502。 |
    | TCP 帧模式 | ✘ | 支持以下值：<ul><li>Modbus TCP</li><li>RTU Over TCP</li><li>ASCII Over TCP</li></ul> |

  - 高级配置：   
    | 参数名称 | 是否必填 | 说明 |
    | --- | --- | --- |
    | 是否启用批量写入线圈指令 | ✔ | 是否使用 "Force Multiple Coils" 指令写多个线圈（对应 Modbus 协议中的功能码 15）。 |
    | 是否启用批量写入寄存器指令 | ✔ | 是否使用 "Preset Multiple Registers" 指令写多个保持寄存器（对应 Modbus 协议中的功能码 16）。 |
    | 浮点数字节序 | ✔ | 32 位浮点数的读写顺序，支持如下：<ul><li>Order BADC</li><li>Order ABCD（默认）</li><li>Order CDAB</li><li>Order DCBA</li></ul> |
    | 长整型字节序 | ✔ |  32 位 Int32/UInt32，占两个连续寄存器，支持如下：<ul><li>Order BADC</li><li>Order ABCD（默认）</li><li>Order CDAB</li><li>Order DCBA</li></ul> |
    | 是否覆盖网络配置 | ✔ | 不开启则使用 network 的字节序配置，当前字节序配置无效。 |
    | rxProcessMode | ✔ | 接收数据处理模式，支持以下值：<ul><li>Byte</li><li>Packet</li></ul> |

4. 在步骤 2 单击 **手动添加** 按钮，以进入添加功能点流程。   
    ![点击手动添加按钮](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/ModbusTCP-ManuallyAdd.png)

5. 在功能点列表单击 **+** 按钮，以添加一个功能点。

    ![添加并配置点位](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/ModbusTCP-AddAndConfigurePoints.png)

    添加点之后，您可以配置该点的如下类型参数：**点添加**、**类型设置**和**数据映射规则**。

    - **点添加**：   
        | 参数名称 | 是否必填 | 参数说明 | 配置示例 |
        | - | - | - | - |
        | 功能点名称 | ✔ | 您自定义的功能点名称。 | - |
        | 轮询频率 | ✘ | 用于控制该点位的轮询频率。支持以下选项：<ul><li><strong>快速</strong>：为 1 秒，高频轮询（适用于关键控制）</li><li><strong>正常</strong>：为 5 秒，常规频率</li><li><strong>慢速</strong>：为 30 秒，低频轮询（适用于非实时状态）。</li></ul>此配置主要在点位独立读取时生效；如果启用了设备级轮询，实际刷新频率可能会以设备轮询组配置为准。| 正常 |
        | 寄存器类型 | ✔ | 支持以下：<ul><li><strong>保持寄存器</strong></li><li><strong>输入寄存器</strong></li><li><strong>离散线圈</strong></li><li><strong>离散输入</strong></li></ul> | 保持寄存器 |
        | 访问类型 | ✘ | 支持以下：<ul><li><strong>只读</strong></li><li><strong>读写</strong></li></ul> | 读写 |
        | 寄存器地址格式 | ✔ | 地址格式类型，支持以下：<ul><li><strong>十六进制</strong>：如 0013。</li><li><strong>十进制</strong>：如 19。</li><li><strong>标准 Modbus 地址</strong>：如 00001、10001、30001、40001。</li></ul> | 十进制 |
        | 寄存器地址 | ✔ | 根据“寄存器地址格式”填写。hex 示例：000A；decimal 示例：10；modbus 示例：00001、10001、30001、40001。 | 10 |
        | 数据类型 | 数值型点必填 | 数据类型 当寄存器类型为 **保存寄存器** 或 **输入寄存器** 时必填，支持以下：<ul><li>UInt16</li><li>Int16</li><li>UInt32</li><li>Int32</li><li>Float32</li></ul> | Int16 |
        | 单位 | 数值型点必填 | 您可以自定义适合此功能点的单位。 | - |
        | 位编号 | 数值型点必填 | 用于从一个 16 位保持寄存器或输入寄存器中读取指定单个位。位编号从 0 开始，范围为 0-15，0 表示最低位。-1 标识不使用该配置。 | -1 |
        | 起始位 | 数值型点必填 | 当一个 16 位寄存器中的连续几位代表一个数值或状态枚举时，填写这段数据的起始位。位编号从 0 开始，范围为 0-15，0 表示最低位。 | 0 |
        | 位数 | 数值型点必填 | 当一个 16 位寄存器中的连续几位代表一个数值或状态枚举时，填写从起始位开始占用的连续位数。范围为 1-16，且起始位 + 位数不能超过 16。当前只支持从单个 16 位寄存器中取连续位段。| 0 |
    - **类型设置**：
        - 当寄存器类型为 **保持寄存器** 或 **输入寄存器** 时：
            
            | 参数类型           | 参数名称   | 是否必填 | 参数说明                                                                                                               | 配置示例               |
            |--------------------|------------|----------|------------------------------------------------------------------------------------------------------------------------|------------------------|
            | Aqara Spec         | -          | ✔        | 用于将此点位关联到 Aqara Spec 协议中的对应功能点，实现标准化控制与管理。                                                | 空调/冷暖控制功能/设置温度 |
            | 功能取值（数值）   | 最小值     | ✔        | 配置数值型功能点的取值范围的最小值。                                                                                   | 16                     |
            |                    | 最大值     | ✔        | 配置数值型功能点的取值范围的最大值。                                                                                   | 30                     |
            |                    | 步长       | ✔        | 配置数值型功能点的取值范围的步长。                                                                                     | 1                      |
            |                    | 单位       | ✔        | 配置数值型功能点的取值范围的单位。                                                                                     | 摄氏度（℃）            |
            |                    | 精度       | ✔        | 配置数值型功能点的取值范围的精度，支持以下：<ul><li>整数</li><li>小数点后 1 位</li><li>小数点后 2 位</li><li>小数点后 3 位</li></ul> | 整数                   |

        - 当寄存器类型为 **离散线圈** 或 **离散输入** 时：

            | 参数类型           | 参数名称   | 是否必填 | 参数说明                                                                          | 配置示例                  |
            |--------------------|------------|----------|-----------------------------------------------------------------------------------|---------------------------|
            | Aqara Spec         | -          | ✔        | 用于将此点位关联到 Aqara Spec 协议中的对应功能点，实现标准化控制与管理。           | 门窗传感器/接触/接触状态    |
            | 功能取值（布尔）   | true 文本  | ✔        | 配置布尔型功能点取值为 true 时显示的文本。                                        | 已关上                    |
            |                    | false 文本 | ✔        | 配置布尔型功能点取值为 false 时显示的文本。                                       | 已打开                    |

    - **数据映射规则**：开启后可对读取到的原始物理数值进行二次逻辑计算与状态映射。相关规则请阅读 [数值映射函数](./../numerical-mapping-functions.mdx)
        - 当点的**寄存器类型**与 **Aqara Spec 类型**不一致时（如数值型需要映射为布尔型，或布尔型需要映射为数值型），请开启此选项，实现物理值与标准功能点类型之间的转换与映射。
        - 若点的**寄存器类型**与 **Aqara Spec 类型**一致，则无需开启本选项。

6. 完成功能点添加后，返回 **设备管理** 页面，即可在 Modbus TCP 节点下看到新增的设备。

    选择该设备，即可在设备详情页面中的 **功能点** 列表中看到新增的功能点。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/ModbusTCP-CheckNewDeviceAndPoint.png" alt="设备详情" />
