# BACnet 设备接入

本文说明如何将 BACnet 设备接入 Aqara Studio。

## 支持的 BACnet 点位对象类型

在将您的 BACnet 设备接入 Aqara Studio 时，请确保其点位对象类型在 Aqara Studio 支持的范围内（如下表所列）：

| 范围 | 对象类型 |
|----|----|
| 模拟量三类 | <ul><li>Analog Input</li><li>Analog Output</li><li>Analog Value</li></ul> |
| 二值三类 | <ul><li>Binary Input</li><li>Binary Output</li><li>Binary Value</li></ul> |
| 多状态三类 | <ul><li>Multi-state Input</li><li>Multi-state Output</li><li>Multi-state Value</li></ul> |
| 扩展映射 | <ul><li>Integer Value</li><li>Binary Lighting Output</li><li>Channel</li><li>Color Temperature</li><li>Lighting Output</li><li>Color</li><li>Accumulator</li></ul> |

## 经测试的 BACnet 设备

以下列出经 Aqara 测试可正常接入 Aqara Studio 的 BACnet 设备：

| 品牌 | 型号 |
|----|----|
| Honeywell | HT9610P0100 |
| 上海迅饶自动化 | HMI2004-ARM |
| 浙江正泰电器 | CHNT DDSU6665 |

## 前提条件

在开始之前，根据您的设备情况，确保以下网络条件满足：
- 对于 BACnet/IP 设备：BACnet/IP 设备、Aqara 网关与电脑处于同一局域网。
- 对于 BACnet MS/TP 设备：BACnet MS/TP 设备已连接 BACRouter，且 BACRouter、Aqara 网关与电脑处于同一局域网。

## 添加功能点

1. 在 BACnet IP 节点下选择一个 BACnet 设备，单击 **添加功能点** 按钮。

    ![Bacnet 功能点页](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/BACnetIP-ClickAddPoint.png)

2. 在“添加功能点”页面，单击 **发现功能点** 按钮，Aqara Studio 即开始扫描发现该设备的功能点。 

    :::tip
    如果本系统没有发现你需要的功能点，您也可以 [手动添加该功能点](#如何处理-aqara-studio-无法发现-bacnet-功能点的问题)。
    :::

    ![Add points](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/BACnetIP-ClickDiscoverPoints.png)

3. 勾选需要的点，单击中间 **+** 按钮。

    ![Add points](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/BACnetIP-AddSelectedPoints.png)

4. 此时，您可以看到 **添加功能点** 弹窗。在左侧的 **功能点** 列表中，选择一个功能点。

    Aqara Studio 会根据点的类型，自动将功能点关联到 Aqara Spec 协议中的同类型功能点。请在左侧 **功能点配置** 中找到 **类型设置 > Aqara Spec**，确认推荐类型是否与该功能点的实际功能一致。如果不一致，请调整为正确功能点。

    ![Configure points](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/BACnetIP-ConfigurePoints.png)

    如果该 BACnet 设备的功能点与您选择的 Aqara Spec 功能点数据类型不一致，系统将触发 **数据映射**。请在 **数据映射规则** 中配置原始数值与 Aqara Spec 目标值之间的映射关系。

    ![数据映射](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/BACnetIP-DataMapping.png)

    完成一个功能点的配置后，可在 **功能点** 列表中选择其他点继续配置。所有功能点配置完成后，单击 **完成** 按钮，退出功能点配置流程。

5. 此时，Aqara Studio 自动添加功能点。新增功能点会出现在右侧的 **已添加功能点** 列表。单击 **完成** 按钮，退出添加功能点流程。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/BACnetIP-PointsAdded.png" alt="已添加功能点" /> 

4. 此时，您将在该 BACnet 设备的管理页面中，看到已成功添加的功能点。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/MQTT-CheckPoints.png" alt="已添加功能点" />
