# UDP 设备接入

本文将指导您如何通过编写 JS 脚本，将 UDP 协议设备接入 Aqara Studio 以及将设备功能点按照 **Aqara 物模型规范** 完成映射，实现设备的发现、添加及功能点控制等操作。

## 经测试的 UDP 设备

以下列出经 Aqara 测试可正常接入 Aqara Studio 的 UDP 设备：
- 满足以下版本要求的曼顿智能空开：
    - 固件版本 3.2.63 及以上
    - Web 版本 1.1.08 及以上

:::tip
如果您希望 Aqara 测试更多产品，请将品牌、型号、产品资料与联系方式发送至 [eco-partnerships@aqara.com](mailto:eco-partnerships@aqara.com)，以便 Aqara 与您进一步沟通。
:::

## 学习并编写 JavaScript 脚本

请参考 [JavaScript 脚本（适用于 UDP 和 TCP）](./../javascript-for-udp-tcp-integration.mdx) 的编写方法，编写符合 **Aqara 物模型规范** 的 JavaScript 脚本。此脚本将用于指导 Aqara Studio 如何发现设备、添加与控制功能点等。

## 安装插件

请参考 [插件市场](./../plugin-center.mdx) 文档：
1. 前往 [Aqara Builder 工坊 - 市场](https://builder.aqara.com/lab/plugin-store) 获取 `UDP Protocol Access` 插件。
2. 将其分配到 Aqara Studio。
3. 并前往 Aqara Studio 的 **插件中心** 安装该插件。

## 添加 UDP 设备

1. 在左侧侧边栏点击进入**设备管理**页面。在左侧 **协议和设备** 单击 **...** 按钮，选择 **添加协议**。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Devices-AddProtocol.png" alt="添加协议" /> 

2. 在弹窗中选择 `UDP`，以添加一个 UDP 节点。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Devices-SelectUDP.png" alt="添加 UDP" style={{width: '70%'}} /> 

3. 选择该节点，进入管理界面。点击 **协议配置** 按钮。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/UDP-ProtocolConfiguration.png" alt="协议配置" /> 

4. 在弹窗中单击 **脚本配置** 按钮。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/UDP-ScriptConfiguration.png" alt="脚本配置" style={{width: '60%'}} /> 

5. 将 [编写好的 JavaScript 脚本](#学习并编写-javascript-脚本) 粘贴到代码框中，确保 UDP 设备及其功能点能被 Aqara Studio 正确识别和管理。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/UDP-ScriptEditor.png" alt="代码粘贴至脚本编辑器" style={{width: '60%'}} /> 

6. （可选）如果您希望用 `msgId` 来匹配发送消息与接收消息，请启用 `Match by msgId` 开关。若无启用，则表示按顺序处理。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/UDP-MsgIdMatch.png" alt="消息 ID 匹配" style={{width: '60%'}} /> 

7. 返回 UDP 管理页面，单击 **添加设备** 按钮。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/UDP-AddDevice.png" alt="单击添加设备按钮" /> 

8. 在弹窗中选择 **自动发现** 作为接入方式，并选择 **开始接入设备** 进入下一步。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/UDP-SelectAutoDiscovery.png" alt="选择自动发现作为接入方式" style={{width: '60%'}} /> 

9. （可选）单击 ⚙ 图标。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/UDP-Gear.png" alt="单击齿轮图标" /> 

    :::tip
    如果没有 UDP 服务端，可以跳过该设置。此时，建议在 [JS 脚本](#学习并编写-javascript-脚本) 中 [parseDiscoveryResponse](./../javascript-for-udp-tcp-integration.mdx#parsediscoveryresponse) 的返回结果里直接写明目标 UDP 设备的 IP 和端口号，实现设备的精准发现和接入。
    :::

    在弹窗内填写 UDP 服务端的 IP 地址和端口号。该信息将用于 [JS 脚本](#学习并编写-javascript-脚本) 中的 [buildDiscoveryRequest](./../javascript-for-udp-tcp-integration.mdx#builddiscoveryrequest) 接口，指导 Aqara Studio 从指定地址自动发现所有 UDP 设备。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/UDP-DiscoveryConfiguration.png" alt="配置服务端 IP 地址和 Port" style={{width: '50%'}} />

10. 选择 **发现设备** 按钮。

    Aqara Studio 会根据您编写的 [JS 脚本](#学习并编写-javascript-脚本) 自动扫描并识别可接入的 UDP 设备，被发现的设备会在**发现设备列表**中展示。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/UDP-DiscoverDevices.png" alt="发现设备" /> 

11. 选择需接入的设备，点击中间“+”按钮。

    新增设备会出现在右侧的已添加设备列表。单击 **完成** 按钮，退出添加设备流程。


12. 此时，您将在左侧 **协议和设备** 的 UDP 节点下，以及该 UDP 管理页面的设备列表中，看到已成功添加的设备。

## 添加功能点

1. 在 UDP 节点下选择一个 UDP 设备，单击 **添加功能点** 按钮。


2. 选择 **发现功能点** 按钮。

    :::tip
    - 若设备功能点为**动态**，请在 [JS 脚本](#学习并编写-javascript-脚本) 中实现 [buildDiscoverPointsRequest](./../javascript-for-udp-tcp-integration.mdx#builddiscoverpointsrequest) 接口和 [parseDiscoverPointsResponse](./../javascript-for-udp-tcp-integration.mdx#parsediscoverpointsresponse) 接口。   
    此时，点击 **添加功能点** 按钮，Aqara Studio 会调用 [buildDiscoverPointsRequest](./../javascript-for-udp-tcp-integration.mdx#builddiscoverpointsrequest) 接口以动态发现设备功能点，并会将该接口的返回值作为 [parseDiscoverPointsResponse](./../javascript-for-udp-tcp-integration.mdx#parsediscoverpointsresponse) 接口的入参。
    - 若设备功能点为**静态**，请在 [JS 脚本](#学习并编写-javascript-脚本) 中实现 [parseDiscoverPointsResponse](./../javascript-for-udp-tcp-integration.mdx#parsediscoverpointsresponse) 接口，并在返回值中**直接提供目标设备的功能点列表**。   
    此时，点击 **添加功能点** 按钮，Aqara Studio 将直接发现这些功能点。
    :::

3. 在 **发现功能点列表** 勾选需要的点，单击中间 **+** 按钮。
    
    新增功能点会出现在右侧的 **已添加功能点** 列表。单击 **完成** 按钮，退出添加功能点流程。

4. 此时，您将在该 UDP 设备的管理页面中，看到已成功添加的功能点。
