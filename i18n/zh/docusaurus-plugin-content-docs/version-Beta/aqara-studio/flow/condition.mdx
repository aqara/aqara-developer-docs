# 判断

本文说明 Flow 的判断类卡片。

## 概述

在自动化 Flow 中，判断类卡片用于对流程中的数据、设备状态或变量等进行条件判定，是流程分支控制的重要节点。

判断卡片通常拥有两个输出点，分别对应判断结果为 true（满足条件）或 false（不满足条件）。只有在某一输出路径被激活时，后续的动作或分支才会被执行。

通过配置不同类型的判断卡片，可以灵活实现数据比较、逻辑运算等条件判断，使自动化流程具备复杂的智能分支处理能力，满足多样化的业务需求。

在 Flow 中，以下内容都可进行判断：
- [设备](#设备)：判断设备的当前状态或其某项数据是否满足设定条件，例如“灯是否已打开”、“温度是否超过阈值”等。
- [触发值](#触发值)：读取当前自动化中已选的 [设备类触发卡片](./trigger.mdx#设备) 所携带的触发值，将其与此卡片上设定的值进行比较，并从满足、不满足分支继续执行。
- [逻辑](#逻辑)：用与、或、异或、非组合多个是否条件；也可对任意两个数据做等于、不等于、大于、小于、大于等于或小于等于比较。比较完成后，从满足或不满足分支继续执行。
- [时间](#时间)：判断当前时间是否处于指定的时间区间，例如判断“是否为周一 10 点至 12 点”，实现与时间相关的自动化分支。
- [自动化](#自动化)：判断选中的自动化当前是启用还是禁用，并从满足或不满足分支继续执行。这里看的是启停状态，不是流程是否正在运行，也不是这次执行是否成功。

## 判断类输出点说明

判断类卡片的输出点通常有两个，分别代表判断的结果：

- **True 输出**：当判断条件满足（即结果为 true）时，流程将从此输出点继续执行。
- **False 输出**：当判断条件不满足（即结果为 false）时，流程将从此输出点继续执行。

如下图所示：

![判断卡片输出点说明](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-ConditionOuputs.png)

开发者可根据实际自动化需求，分别在 true 和 false 输出下配置不同的后续卡片，实现流程的分支和差异化处理。例如，在设备状态达到设定条件时执行某些操作，否则执行另一组操作，从而提升自动化的灵活性和智能性。

## 设备

在自动化执行到此卡片时，判断指定设备属性是否满足比较条件（“某灯是否打开”、“温湿度是否超过指定阈值”），可附加状态持续时长要求。根据结果从满足或不满足分支继续执行。

开发者可通过配置设备以及其对应的功能点、状态或数值，并设置判断条件（如等于、不等于、大于、小于等），灵活实现针对设备状态的精准判定。

### 使用步骤

1. 在画布的左侧边栏单击 **+** 按钮。在**判断**下选择**设备**。在设备列表中选择待判断的设备。

    ![选择设备](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-SelectADeviceCondition.png)

2. 随后，您可以看到该设备可用的卡片列表，即该设备的可读功能点列表。单击所需卡片。即可将该卡片添加到画布。

    ![选择设备判断卡片](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-SelectAConditionPointCard.png)

    ![基于设备的判断卡片已添加到画布](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-DeviceConditionAdded.png)

3. 单击卡片上的第一个参数，可选择设备的具体判断条件（如等于、不等于、大于、小于等）。

    :::tip
    不同类型的设备功能点可选的监听条件各异。例如，开关类型一般支持“等于”、“不等于”等选项，而数值类功能点还支持“大于”、“小于”等选项。
    :::

    ![修改判断条件](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-DeviceConditionEventSelection.png)

    单击第二个参数，您还可以进一步指定需要监听的数据目标。

    ![制定监听数据](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-DefineConditionValue.png)

4. 完成上述配置后，需确保该判断卡片的输出点（True 或 False 输出）中至少有一个已连接到其他卡片（[判断类卡片](./condition.mdx) 或 [执行类卡片](./action.mdx)）。

## 触发值

此判断卡片是通过读取当前自动化中已选的 [设备类触发卡片](./trigger.mdx#设备) 所携带的触发值，将其与此卡片上设定的值进行比较，从而判断是否满足条件。

此判断卡片不会重新查询设备当前状态。

### 前提条件

您需要先在自动化中添加一个 [设备类触发卡片](./trigger.mdx#设备)，才能将触发值用于判断。

### 使用步骤

1. 在左侧边栏单击 **+**。在**判断**下选择**触发值**，再选择一张已经添加的[设备类触发卡片](./trigger.mdx#设备)。

    ![选择事件源](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TriggerValue-SelectAnEventSource.png)

2. 单击一条触发值判断，将其添加到画布。

    ![单击添加触发值判断卡片](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TriggerValue-ClickToAddTriggerValueCondition.png)

3. 在卡片上把第一个参数设为比较方式，例如等于、不等于、大于或小于。

    ![设置比较条件](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TriggerValue-SetComparisonCondition.png)

4. 把第二个参数设为要比较的值。

    ![设置比较参数](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TriggerValue-SetComparedParameter.png)

5. 至少将一个输出点（True 或 False）连接到另一张[判断类卡片](./condition.mdx)或[执行类卡片](./action.mdx)。


## 逻辑

判断类卡片中与逻辑相关的类型主要有 [比较运算](#比较运算) 和 [逻辑运算](#逻辑运算)。  
- **比较运算**用于判断两组数据之间的关系（如等于、不等于、大于、小于等），用于实现数值、状态等条件的判断。  
- **逻辑运算**则用于对多个条件判断结果（如多个判断卡片的输出）进行逻辑关系组合（如与、或、异或），实现更为复杂的条件分支控制。  

开发者可根据实际需求灵活选用前述卡片类型，构建多样化的判断逻辑。

### 比较运算

比较运算用来比较两组数据，例如设备数据、变量、触发数据或自定义值。可以判断两者是否相等，也可以比较大小，或判断数值是否上升、下降并越过阈值。比较完成后，从满足或不满足分支继续执行。


当比较条件成立时，卡片会输出 true，否则输出 false。通过灵活配置比较运算，可以实现对设备状态、变量值等的精准判定，从而控制后续自动化流程的分支走向。例如，可以判断“温度是否超过阈值”，有效提升自动化决策的智能化与多样性。

#### 使用步骤

1. 在画布的左侧边栏单击 **+** 按钮。在**判断**下选择**逻辑**。单击**比较运算**，即可在画布上添加该卡片。

    ![选择比较运算](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-SelectComparison.png)

2. 单击卡片上的第一个参数，即可从下拉列表中选择一个设备数据作为数值 A。

    ![选择数值 A](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-SelectValueA.png)

    若需对比变量值，只需点击 &#128279; 图标，即可从变量列表中选择所需变量参与比较。

    ![使用变量](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-UseVariable.png)

3. 单击卡片上的第二个参数，即可设置比较运算符，如大于。

    ![设置运算符](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-SetComparison.png)

4. 单击卡片上的第三个参数，设置数值 B。设置方式与数值 A 相同。
5. 完成上述配置后，需确保该判断卡片的输出点（True 或 False 输出）中至少有一个已连接到其他卡片（[判断类卡片](./condition.mdx) 或 [执行类卡片](./action.mdx)）。

### 逻辑运算

逻辑运算用来组合多个是否条件，支持与、或、异或和非。与要求全部为真，或要求至少一个为真，异或要求为真的个数是奇数，非只把第一个条件取反。运算完成后，从满足或不满足分支继续执行。


#### 使用步骤

1. 在画布左侧边栏**判断**下选择**逻辑**，添加“逻辑运算”卡片。

    ![选择逻辑运算](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-SelectLogicalOperation.png)

2. 点击卡片上的逻辑类型参数，从下拉选项中选择所需的逻辑运算方式（如“与”、“或”、“异或”或“非”）。

    ![设置规则](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-SetLogicalOperationRule.png)

3. 单击 “+” 按钮，为逻辑运算卡片添加输入项。可添加的布尔值类别包括：
   - 判断类卡片的输出；
   - 布尔型变量（支持全局变量、局部变量及设备相关的布尔数据）。
   
    ![添加布尔值](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-AddBooleanValues.png)

4. 完成上述配置后，需确保该判断卡片的输出点（True 或 False 输出）中至少有一个已连接到其他卡片（[判断类卡片](./condition.mdx) 或 [执行类卡片](./action.mdx)）。

## 时间

判断类卡片中与时间相关的类型主要有 **周期判断**、**日期类型判断**、**年度日期范围判断** 和 **定期判断**。  

| 判断类型       | 适用场景描述                                                         | 示例                                              |
|--------------|--------------------------------------------------------------------|--------------------------------------------------|
| **周期判断**   |判断当前时间是否处于所选星期的指定时间范围内，支持跨午夜的时间段，并根据结果从满足或不满足分支继续执行。时间可使用指定时刻，或基于经纬度的日出、日落及其偏移。 | 每周一至周五 09:00-18:00               |
| **日期类型判断** | 按系统时区判断当前日期是否属于中国区日历中所选日期类型。日历数据不可用时判断失败，更新后自动恢复。| 工作日（含调休补班） |
| **年度日期范围判断** | 判断当前日期是否在每年重复的起止月日内，包含起止日，支持跨年。 | 每年 11 月 19 日至 12 月 20 日 |
| **定期判断**   | 判断当前时间是否在指定的开始和结束日期时间之间，包含边界，并根据结果从满足或不满足分支继续执行。时间可使用指定时刻，或基于经纬度的日出、日落及其偏移。           | 2026/01/01 12:00:00 - 2026/01/02 13:00:00  |


### 使用步骤

1. 在画布左侧边栏**判断**下选择**时间**。单击任意卡片，即可在画布上添加该卡片。

    ![选择时间相关的判断卡片](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-AddTimeCondition.png)

2. 配置参数：
    - 对于 **周期判断**：
        - 点击卡片上的第一个参数，选择需要判断的星期几（支持多选）。
        - 点击卡片上的第二个和第三个参数，分别设置起始和结束时间。

        ![设置周期判断的参数](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-SetPeriodicConditionParameters.png)
    
    - 对于 **日期类型判断**：
        - 点击卡片上的参数，选择日期类型为工作日、法定节假日或休息日。

    - 对于 **年度日期范围判断**：
        - 点击卡片上的第一个参数，选择需要范围的开始日期（月/日）。
        - 点击卡片上的第二个参数，选择需要范围的结束日期（月/日）。

    - 对于 **定期判断**：
        - 点击卡片上的起始参数，设置起始的具体日期和时间；
        - 点击卡片上的结束参数，设置结束的具体日期和时间。
        
        ![设置定期判断的具体日期和时间](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-SetSpecificDateandTime.png)

3. 完成上述配置后，需确保该判断卡片的输出点（True 或 False 输出）中至少有一个已连接到其他卡片（[判断类卡片](./condition.mdx) 或 [执行类卡片](./action.mdx)）。
    
## 自动化

此卡片用于判断选中的自动化当前是启用还是禁用，并从满足或不满足分支继续执行。

:::tip
这里判断的是自动化是否启用，而不是流程是否正在运行，也不是判断该自动化执行是否成功。
:::

### 使用步骤

1. 在画布左侧边栏单击 **+**。在**判断**下单击**自动化**，在画布上添加一个自动化判断卡片。

    ![添加自动化判断卡片](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AutomationCondition-AddABlock.png)

2. 选择一个要判断启停状态的自动化。

    ![选择自动化](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AutomationCondition-SelectAnAutomation.png)


2. 在卡片上设置要匹配的状态：`已启用` 或 `已禁用`。

    ![选择自动化状态](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AutomationCondition-SelectAnStatus.png)

3. 完成上述配置后，需确保该判断卡片的输出点（True 或 False 输出）中至少有一个已连接到其他卡片（[判断类卡片](./condition.mdx) 或 [执行类卡片](./action.mdx)）。
