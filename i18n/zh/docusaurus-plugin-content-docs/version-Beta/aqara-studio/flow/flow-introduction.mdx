# Flow

通过灵活的可视化配置能力，您可以基于各类卡片组成数据流逻辑，快速构建适用于多种场景的自动化流程，轻松实现物联网设备的智能控制与协同运行。

## 前提条件

在开始之前，请确认已在 Aqara Studio 添加设备，相关操作流程请阅读 [设备接入](/docs/category/device-integration) 文档。

## 创建自动化

在左侧导航栏单击 **自动化**。在 **自动化** 标签下单击 **创建** 按钮。   
    
![单击创建按钮](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Flow-ClickCreate.png)    

## 更名自动化

在编辑器中，单击左上方的自动化名称区域，即可更名。

![更名自动化](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Flow-Rename.png)    

## 分配自动化至空间

在自动化名称区域下方，您可以为该自动化选择并分配所属空间。

![分配自动化至空间](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Flow-AssignFlowToSpace.png)    

## 添加卡片

### 什么是卡片？

在 Aqara Studio 中，**卡片**在自动化中扮演着“信息中枢”和“控制枢纽”的角色。它将后台复杂的自动化逻辑（如“有人且光线暗就开灯”）转化为清晰可视的设备状态和一键触发的场景开关，让无形的自动化变得直观、可控。

### 添加步骤

1. 在画布的左侧边栏单击 **+** 按钮。
2. 浏览并选择所需的卡片类型（如触发类、判断类、执行类）。
3. 在所选卡片类型下，进一步选择具体的卡片。例如，在**触发**类下单击**时间**，可以看到 **周期触发**、**定期触发** 和 **循环触发** 这三个卡片。
4. 单击所需的卡片，即可添加到画布。

![单击加号，选择详细的卡片，](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-HowtoAdd.png)

### 组成要素

卡片包含以下要素：

| 要素 | 说明 |
| -- | -- |
| 输入点 | 当卡片拥有输入点时，表示其可被触发。 |
| 参数 | 可用于设置需要关注的状态、执行的动作或其他操作。|
| 输出点 | 当卡片拥有输出点时，表示其可触发其他步骤。 |

### 卡片类别

Flow 支持以下类型的卡片，作用如下：

| 类别 | 说明 |
| -------- | ---- |
| [触发](./trigger.mdx) | Flow 的**起始节点**。<br />可由设备状态变化（如灯被打开）、定时触发、告警事件等多种条件发起，用于启动流程。 |
| [判断](./condition.mdx) | Flow 的**中间节点**。<br />用于判定设备状态、时间、各类逻辑与比较运算等是否满足设定条件，并据此决定流程走向。|
| [执行](./action.mdx) | Flow 的**终点节点**。<br />用于下发和执行多种动作，包括单个或批量设备控制、数据处理、延时等，实现自动化流程的闭环。 |

### 连接线说明

不同[类别](#卡片类别)的卡片，其连接方式如下：

- [触发](./trigger.mdx)：仅有输出点，无输入点。一个触发卡片的输出可以连接至多个其他卡片，作为流程的起点。
- [判断](./condition.mdx)：既有输入点，也有输出点。多个卡片的输出可连接至同一个判断卡片的输入；判断卡片的每个输出（如不同判断结果）同样可分别连接到多个后续卡片，实现流程分支。
- [执行](./action.mdx)：作为流程的终点，支持多个输入点，可由多个卡片同时触发；根据实际需求，也可设置多个输出点用以扩展后续流程。

:::tip
Flow 卡片的输入输出主要用于流程控制，即控制流程的走向。例如，多输入意味着多个卡片的流程可汇聚至同一张卡片，多输出则表示一个卡片的流程可分流至多个后续步骤。

这些输入输出与实际“数据”的流转无关，数据的处理和运算均在卡片内部完成，而不会在卡片间直接传递。

此外，[判断类卡片](./condition.mdx) 的输出具备 true/false 两种分支结果，用于进一步控制流程分支。
:::

### 卡片操作

添加卡片到画布后，您可通过右键单击卡片，打开操作菜单，实现对该卡片的重命名、复制、测试及删除等操作。

## 添加变量

### 变量可以用作什么？

您可以在Flow 中创建变量，用于作为 [触发](./trigger.mdx#变量触发) 节点，参与 [比较运算](./condition.mdx#比较运算)、[数学运算](./action.mdx#数学运算) 和 [数据聚合](./action.mdx#数据聚合) 等操作。同时，还可以通过相应的卡片对变量进行 [修改](./action.mdx#变量修改) 或 [切换](./action.mdx#变量切换)，让流程更加灵活智能。

### 变量类别

Flow 中的变量可以分为 **全局变量** 和 **局部变量**，它们的应用范围区别如下：

| 类型     | 应用范围                                   |
|--------|----------------------------------------|
| 全局变量 | 可在所有 Flow 内共享与使用。            |
| 局部变量 | 仅在创建它的 Flow 内有效，无法被其他 Flow 引用。 |

### 创建变量

创建变量流程：

1. 在画布左侧边栏点击变量图标，展开变量抽屉后点击**添加**按钮。

    ![添加变量](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-AddVariable.png)

2. 在弹出的**新增变量**窗口中，选择数据类型、设置变量名称、输入初始值，并选择其作用范围（全局或局部）。填写完毕后点击**保存**。

    ![配置变量](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-VariableConfiguration.png)

3. 变量创建后，可通过变量抽屉顶部的筛选分别查看全局变量或局部变量，就可以找到您新增的变量。

    ![配置变量](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AdvancedFlow-FindVariable.png)

## 调试与测试

在画布上添加完卡片和变量，并完成连接后，您可以进行 [调试](#调试) 和 [测试](#测试)，以确保自动化流程的正确性。

### 调试

调试用于检查自动化流程中各卡片之间的流转是否顺畅无阻碍。

:::tip
在调试模式下，Aqara Studio 不会下发模拟值来模拟触发条件，因此不会真实触发设备执行操作。
:::

操作步骤如下：
1. 在画布左上方启用 **调试模式**。
2. 单击 **▶** 图标，打开 **测试运行** 列表。该列表会显示画布上所有的 [触发](./trigger.mdx) 卡片。
3. 在列表中选择一个 [触发](./trigger.mdx) 卡片。Aqara Studio 将视该触发条件为已满足，并开始执行其后的自动化流程。
4. 等待提示 **流程测试已完成**，即表示流程已通过调试，可以正常执行。

![调试](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Flow-EnableDebugMode.png)

### 测试

测试，用于模拟触发条件被满足，从而触发自动化流程的执行。您可以观察 [执行事件](./action.mdx) 是否被正确完成（如设备状态是否发生改变、流程是否被启用等）。

操作步骤如下：
1. 单击 **▶** 图标，打开 **测试运行** 列表。该列表会显示画布上所有的 [触发](./trigger.mdx) 卡片。
2. 在列表中选择一个 [触发](./trigger.mdx) 卡片。Aqara Studio 将视该触发条件为已满足，并开始执行其后的自动化流程。
3. 等待提示 **流程测试已完成**，即表示流程已通过测试，可以正常执行。并且观察 [执行事件](./action.mdx) 是否被正确完成（如设备状态是否发生改变、流程是否被启用等）。

![调试](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Flow-Test.png)

## 保存

完成上述配置、调试和测试后，确认当前自动化编排无误，即可点击 **保存** 按钮，将自动化保存至 Aqara Studio 中。

![调试](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Flow-Save.png)

此时页面会跳转至自动化列表，您可以在列表中看到您刚保存的自动化，并且默认已启用。

![自动化列表](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Flow-List.png)
