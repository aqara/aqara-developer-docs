# Data Export by MQTT

You can use the MQTT broker built into Aqara Studio, or integrate your own MQTT broker, to forward device data to third-party platforms so they can query and control connected devices.

:::tip
This guide uses the MQTTX desktop app to show how to connect to MQTT and how to subscribe to and publish messages.
:::

## What can you do with MQTT export?

With MQTT export, you can send request messages through an MQTT Broker using publish/subscribe, and call the data export HTTP APIs that are already available. You can also keep the connection alive with a heartbeat, subscribe to or unsubscribe from device data, and receive device data changes and other object events.

For the JSON objects used in the request and response bodies of these features, see Aqara Developer [Studio Local Development - MQTT](./../aqara-developer/data-export-api/mqtt-api/mqtt-api.mdx).

## Install the Plugin

Refer to the [Plugin Market](./plugin-center.mdx) documentation:
1. Go to [Aqara Builder Lab - Marketplace](https://builder.aqara.com/lab/plugin-store) and get the `MQTT Export` plugin.
2. Assign it to Aqara Studio.
3. In Aqara Studio, open **Plugin Center** and install the `MQTT Export` plugin.

## Enable the MQTT Export Service

1. In the left sidebar of Aqara Studio, open **Plugin Center**, find the `MQTT Export` plugin, and click **Transfer Out**.

    ![Find the MQTT Export plugin in Plugin Center and click Transfer Out](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-ClickTransferOut.png) 

2. You are taken to the **Developer** page. **Enable MQTT transfer out**.

    ![Enable the MQTT export service](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-EnableMQTTTransferOut.png) 

## Choose a Broker

Choose a Broker that fits your setup:
- If you do not have your own MQTT Broker, [use the local Broker built into Aqara Studio](#use-the-local-broker).
- If you do not want to use the Broker built into Aqara Studio, [use a third-party Broker](#use-a-third-party-broker).

### Use the Local Broker

To use the local Broker built into Aqara Studio, select **Local Broker**.

Aqara Studio connects to this Broker by default.

![Use the local Broker](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTTExport-SelectLocalBroker.png) 

If the status is **Disconnected**, choose **... > Connect** to connect manually.

![Connect manually](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTTExport-ConnectToLocalBroker.png) 

### Use a Third-Party Broker

To use a third-party MQTT Broker:
1. Select **Third-party Broker** and fill in the following:

    | Name | Description |
    |----------|----------------------------|
    | HOST | Address of the third-party MQTT Broker. |
    | Port | Port number of the third-party MQTT Broker. |
    | Client ID | The **unique** client identifier Aqara Studio uses to connect to this Broker. |
    | Username | Username required to connect to the third-party MQTT Broker. |
    | Password | Password required to connect to the third-party MQTT Broker. |
    | Enable TLS | Whether to use TLS for encrypted transport.<ul><li>On: the MQTT Broker address must use the MQTTS protocol.</li><li>Off: use the MQTT protocol.</li></ul> |

    ![Select a third-party Broker](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTTExport-SelectThirdPartyBroker.png) 

2. (**If TLS is enabled**) Provide the following, depending on whether you want one-way or mutual authentication:

## Test the MQTT Broker Connection

:::tip
- Before you start, download and install the [MQTTX](https://mqttx.app/downloads) desktop app, or another MQTT client.
- The steps below use MQTTX as an example. For other MQTT clients, see their official documentation.
:::

1. On the **Developer** page in Aqara Studio, get everything you need to connect to MQTT (such as HOST, port, username, and password), as well as the request and response topic formats.

    The following figure uses the local Broker as an example:

    ![Get the MQTT connection information](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTTExport-FindInfo.png) 

2. Follow the official MQTTX doc [Getting Started - Connect](https://mqttx.app/docs/get-started#connect), and use the information from the previous step to make the MQTT connection.

    ![Connect via MQTT](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/mqtt-export-2.png) 

3. After you connect, click **New Subscription**.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/MQTTX-NewSubscription.png" alt="New subscription" style={{width: '60%'}} /> 

    Use the **Response Topic Format** shown in Aqara Studio. Replace the ClientID in the topic with the actual ClientID automatically generated by MQTTX to subscribe to response messages.

    Set QoS to 1, then click **Confirm** to create the subscription.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/mqtt-export-3.png" alt="Subscribe to a response" style={{width: '60%'}} /> 

4. In the subscription you just created, replace the ClientID in the **Request Topic Format** from Aqara Studio with the actual ClientID automatically generated by MQTTX, and enter it in the Topic field.
    
    Write a JSON message using the request parameters for each API in Aqara Developer [Studio Local Development - MQTT](./../aqara-developer/data-export-api/mqtt-api/mqtt-api.mdx), then send it to get a response.

    The following figure uses a [subscribe to all device data](./../aqara-developer/data-export-api/mqtt-api/mqtt-api.mdx#subscribe-to-all-or-specific-devices) request as an example:

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/mqtt-export-4.png" alt="Send a request" style={{width: '70%'}} /> 

    The following is a sample response:

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/mqtt-export-5.png" alt="Receive a response" style={{width: '70%'}} />
