# Developer Guide


This document is designed to help developers expand the platform’s capabilities, enabling deep integration and custom development. Whether you want to build personalized applications using the API, or connect devices to mainstream smart home systems, you will find detailed guidance here.

Before starting to use the API v1, you need to [obtain the Studio’s access address and Token](#obtain-required-information). This information is required for request URLs and authentication.

## Obtain Required Information

Before using the API v1, you must first get a Studio access address and Token. These details are used for composing the request endpoint and for authentication.

### Obtain Access Address

You can use the local IP address as the baseUrl to access Aqara Studio APIs: 
1. Go to the **Settings** page from the left navigation bar.
2. In the sidebar, choose **Network Settings** to view the **IP address** in the current network mode.
    ![IP Address Acquisition](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/DeveloperGuide-FindIPAddress.png)

### Obtain Token

Follow these steps:

1. In the left sidebar, navigate to the “Developer” page. In the **Open API & MCP Access** section, enable the service and click the **New Token** button.

    ![Click New Token Button](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/DeveloperGuide-EnableTheServiceAndCreateAToken.png)

2. In the popup, define the token name and validity period. Click the **Confirm** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Developer-DefineToken.png" alt="Define Token Name and Validity Period" style={{width: '80%'}} />

    Afterwards, you will see a popup indicating the Token was created successfully and displaying the token.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/DeveloperGuide-NewTokenCreatedSuccessfully.png" alt="Token Created Successfully" style={{width: '80%'}} />

3. In the **Open API & MCP Access** section, you can see the newly added Token entry.

4. (Optional) To restrict the API access permissions of this Token, click **… > API Configuration**.

    ![API Configuration](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Token-ConfigureAPIs.png)

    In the **API Configuration** popup, uncheck the APIs you do not need, then click the **Confirm** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Token-Uncheck.png" alt="Uncheck unneeded API endpoints" style={{width: '80%'}} />

5. (Optional) In addition to calling APIs, this Token can also be used for MCP services. To enable MCP services, click the **MCP Service** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/DeveloperGuide-EnableMCPService.png" alt="Enable MCP service" style={{width: '80%'}} />

    To restrict the MCP service capabilities of this Token, click **… > MCP Capability Configuration**.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/DeveloperGuide-ConfigureMCP.png" alt="MCP capability configuration" style={{width: '80%'}} />

    In the **MCP Capability Configuration** popup, uncheck the MCP capabilities you do not need, then click the **Confirm** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/DeveloperGuide-UncheckMCPCapabilities.png" alt="Uncheck unneeded MCP capabilities" style={{width: '80%'}} />

6. After completing the configuration above, click the copy icon to obtain the Token.

    ![Copy Token](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/DeveloperGuide-CopyTheToken.png)

## Call the API

With the complete API, you can programmatically obtain device data, control devices, and subscribe to real-time messages. You may want to:
- Query the device list and their status.
- Remotely control device operations.
- Integrate device data into your own system.
- Develop a customized device management experience.

Please refer to the [API documentation](./../aqara-developer/data-export-api/introduction.mdx) for detailed API descriptions and usage instructions.
