## Product Overview

The Edge Box GX500M is an industrial-grade RK3588J fanless embedded industrial PC with Aqara Studio cross-protocol management built in, designed for B2B projects such as large buildings, commercial buildings, and smart factories for multi-protocol access and centralized management. It offers strong computing power and rich interfaces, supports local LAN access, and enables internet remote proxy access via the Aqara IoT cloud, helping build flexible, secure, and efficient smart space systems.

:::note
This product is an Aqara Studio edge host (host role, not a sub-hub), uses wired onboarding, and does not support the Aqara Home app.
:::

## Installation Instructions

### Installation Prerequisites

Supports standard desktop installation, book-style wall mounting, DIN rail mounting, and VESA mounting; a DIN rail mounting kit is included.

- Use the included 12V⎓5A power adapter for power supply;
- Make sure the device is powered off before installation and wiring;
- Do not use in humid, high-temperature, or strong electromagnetic interference environments;
- Keep the heat dissipation surface ventilated; do not block it.

## User Instructions

### Quick Setup

#### 1. Power on

Connect the 12V⎓5A power adapter to the DC-IN interface.

#### 2. Networking (wired)

This product is an Aqara Studio all-in-one device; it requires an HDMI monitor, mouse, keyboard, and network cable for use.

#### 3. Access Aqara Studio

Aqara Studio opens automatically on startup.

#### 4. Connect devices

In Aqara Studio, connect and manage devices by protocol (supported protocols are subject to the Studio compatibility list and plugin authorization).

#### 5. Expansion (optional)

NVMe SSD, 4G/5G modules and other expansions can be installed; see the supplier datasheet for details.

## Troubleshooting Guide

### Fault Symptoms, Possible Causes, and Solutions

Common inability to access Studio:

- Confirm the device and the accessing terminal are on the same LAN;
- Access via the device's default management address or the IP assigned by the router;
- Check the network cable and switch status;
- mDNS may fail across VLANs; use a static IP instead.
