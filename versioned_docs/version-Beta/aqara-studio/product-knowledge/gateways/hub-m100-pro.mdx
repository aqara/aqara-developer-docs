## Product Overview

The Hub M100 Pro is a cost-effective Matter Hub launched by Aqara for Aqara Studio, and connects to the Aqara Studio platform. It supports simultaneous connection of Zigbee and Thread child devices and can be used as a Thread Border Router and Matter Controller. It uses an ARM dual-core A7 SoC at 1GHz and supports 2.4 GHz Wi-Fi 6 wireless connectivity. The product is compact and flexible to install, and can be powered from sockets and appliances with a standard USB-A interface. It can also connect to third-party Matter ecosystems.

:::note
This product has no Ethernet port and does not support wired networking; it only supports wireless (Wi-Fi) connection. It does not support pairing with the Aqara Home app and must be used with the Aqara Life app.
:::

## Installation Instructions

### Installation Prerequisites

Installation tools: none required. Plug the built-in USB-A interface into a power source with a standard USB-A port (socket / appliance / 5V⎓0.5A power adapter) to power the hub.

### Installation Precautions

- Use a compliant 5V⎓0.5A power source; avoid adapters with insufficient output.
- This product has no Ethernet port and only supports wireless (Wi-Fi) networking.
- For indoor use only. Do not use in humid environments or outdoors.
- Do not block the product body or damage the USB-A interface.

## User Instructions

### Quick Setup

#### 1. Power on

Plug the hub into a power source with a standard USB-A interface (socket, appliance, or 5V⎓0.5A power adapter).

#### 2. Wait for startup

The indicator lights up and the hub enters the pairing-ready state (see "Product Features" for indicator descriptions).

#### 3. Pairing (wireless)

This product has no Ethernet port and does not support wired networking; it only supports wireless (Wi-Fi) connection. Complete the initial Wi-Fi configuration via the Aqara Life app, then connect to Aqara Studio (it does not support pairing with the Aqara Home app). See the Aqara Studio pairing guide for details.

#### 4. Connect to Aqara Studio

In Aqara Studio, go to "Device Management → Aqara Hub", click "Discover Devices", search the LAN, and add this hub.

#### 5. Bind child devices

- Bind Zigbee devices: see the Zigbee device pairing guide;
- Bind Thread devices: see the Thread device pairing guide.

#### 6. Reset network parameters / restore factory settings

See the button description in "Product Features".

## Troubleshooting Guide

### Fault Symptoms, Possible Causes, and Solutions

Common pairing failures:

- After power-on, press and hold the hub button for more than 10 seconds, wait until the indicator enters the pairing state, then retry adding;
- Check whether the router has Wi-Fi anti-sharing settings enabled, which may prevent the hub from connecting to the network;
- Check whether the router has AP isolation enabled, which may prevent the hub from being discovered on the LAN;
- Avoid connecting to bridged networks.

## FAQ

### Does Hub M100 Pro support the Aqara Home app?

No. Hub M100 Pro is designed for the Aqara Studio platform; pairing is done via the Aqara Life app, and it does not support pairing with the Aqara Home app.

### Does Hub M100 Pro have an Ethernet port, and can it connect via wired networking?

No Ethernet port; wired networking is not supported. It only supports wireless (Wi-Fi) connection.

### Does Hub M100 Pro support Matter?

Yes. It works as a Matter Controller and Thread Border Router.
