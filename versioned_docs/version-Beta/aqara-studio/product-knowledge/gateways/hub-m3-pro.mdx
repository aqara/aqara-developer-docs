## Product Overview

The Hub M3 Pro is a central hub launched by Aqara for Aqara Studio (internal codename "M3 Studio"), and is a different product from the consumer "Hub M3 / 智慧家庭中枢 M3". It supports Thread border routing, Zigbee 3.0, and Bluetooth multi-mode connectivity, and works as a Matter Controller and Thread Border Router. It uses an ARM dual-core A7 SoC at 1GHz, supports 2.4 GHz / 5 GHz dual-band Wi-Fi and RJ45 wired networking (with PoE power), has eMMC local storage and an RTC clock system for stable time synchronization even offline, an enhanced 6-emitter/1-receiver infrared remote control and speaker, supports table placement, wall mounting, and ceiling mounting, and supports hub replacement and local automation.

Note: This product is designed for the Aqara Studio platform; it does not support pairing with the Aqara Home app.

## Installation Instructions

### Installation Prerequisites

Supports three indoor installation methods: table placement, wall mounting, and ceiling mounting. Wall/ceiling mounting requires the included bracket and screw kit.

### Installation Precautions

- Wire the device only when it is powered off to avoid electrical accidents.
- For PoE power, confirm that the switch/power source supports IEEE 802.3af.
- For adapter power, use a 5V⎓2A adapter with the included Type-C power cable.
- For indoor use only. Do not use in humid environments or outdoors.

## User Instructions

### Quick Setup

#### 1. Power on

Power via Type-C (5V⎓2A) or via PoE on the RJ45 port.

#### 2. Install

Choose table placement, wall mounting, or ceiling mounting as needed.

#### 3. Wait for startup

The indicator lights up and the hub enters the pairing-ready state.

#### 4. Pairing

This product is designed for Aqara Studio and supports both wired and wireless networking:

- Wired: connect to the LAN, then pair via the Studio management page;
- Wireless: complete the Wi-Fi configuration via the Aqara Life app.

It does not support pairing with the Aqara Home app. See the Aqara Studio pairing guide for details.

#### 5. Connect to Aqara Studio

In Aqara Studio, go to "Device Management → Aqara Hub", click "Discover Devices", search the LAN, and add this hub.

#### 6. Bind child devices

Bind Zigbee devices, Thread devices, Bluetooth devices, and IR devices: see the corresponding pairing guides.

#### 7. Reset network parameters / restore factory settings

See the button description in "Product Features".

## Product Features

### Key capabilities

1. Home Hub: cross-LAN and cross-hub local automation execution and multi-hub cluster networking;
2. Matter support: works as Thread Border Router and Matter Controller;
3. Multi-protocol Hub: connects Thread, Zigbee, Bluetooth (BLE), IR RF, and Ethernet devices to Aqara Studio;
4. Hub replacement: supports replacement between M3 Pro Hubs, and M3 Pro replacing M100 Pro, M200 Pro, and AX200M;
5. Local storage: built-in eMMC for local user data storage, reducing cloud dependency;
6. Universal IR control: 6 emitters / 1 receiver, supports IR emission and learning;
7. Offline time sync: built-in RTC clock system maintains device time sync even offline;
8. Custom ringtone: supports uploading custom ringtones for voice announcements;
9. PoE power: PoE powered via the RJ45 port, reducing cabling;
10. Type-C communication: supports expanding peripherals such as 4G/5G dongles for data communication;
11. Dual-band Wi-Fi: 2.4GHz / 5GHz, IEEE 802.11 a/b/g/n/ac.

## Troubleshooting Guide

### Fault Symptoms, Possible Causes, and Solutions

Common pairing failures:

- After power-on, press and hold the hub button for more than 10 seconds, wait until the indicator enters the pairing state, then retry adding;
- Check whether the router has Wi-Fi anti-sharing settings enabled, which may prevent the hub from connecting to the network;
- Check whether the router has AP isolation enabled, which may prevent the hub from being discovered on the LAN;
- When using PoE, confirm that the switch supports IEEE 802.3af;
- Avoid connecting to bridged networks.

## FAQ

### Does Hub M3 Pro support the Aqara Home app?

No. Hub M3 Pro is designed for the Aqara Studio platform; it does not support pairing with the Aqara Home app and does not include the HomeKit ecosystem.

### What is the relationship between Hub M3 Pro and the consumer Hub M3?

They are two different products. Hub M3 is a consumer product, while Hub M3 Pro is the Aqara Studio version (internal codename "M3 Studio").

### Does Hub M3 Pro support PoE power?

Yes. It supports IEEE 802.3af PoE power via the RJ45 port (48V⎓0.27A).
