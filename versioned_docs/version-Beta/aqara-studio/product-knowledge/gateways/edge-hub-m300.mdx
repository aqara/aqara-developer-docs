## Product Overview

Aqara Edge Hub M300 is the official hardware controller for the Aqara Studio spatial intelligence OS. It serves as both a local edge hub and a gateway. Because the Aqara Studio platform is pre-installed and embedded directly in the M300’s solid-state storage (“hub-integrated” model), the device takes on several key architectural roles:

1. Highly available local hardware controller and primary physical commissioning hub;
2. Multi-protocol industrial-grade gateway that bridges wireless topologies with traditional wired building automation standards;
3. Local host server running the Aqara Studio web-based configuration console and user dashboard;
4. High-performance local execution engine for complex multi-threaded scripts and edge automation tasks;
5. Secure local API integration endpoint with a built-in MCP server.

## Installation Guide

### Installation Prerequisites

Use an adapter with a minimum output of 5 VDC 2 A (adapter not included), or power the device via RJ45 using a PoE router/switch that supports IEEE 802.3af.

The product supports desktop placement, wall mounting, and ceiling mounting. When used on a desk, place it on a flat surface and do not block the front IR emitter area.

## User Guide

### Quick Setup

#### 1. Choose a power method

##### 1.1 Type-C power

Use a 5V⎓2A power adapter and the USB-A to USB-C cable to power the hub via the Type-C port (adapter sold separately).

##### 1.2 PoE power

Use a PoE-capable router or network switch connected to the hub’s RJ45 port for both power and network connectivity.

\*Note: When both mains power and PoE are connected, the device draws power from PoE first.

#### 2. Wait for the hub to start

The indicator lights solid yellow; after startup it enters fast yellow flashing (waiting for Studio login/configuration).

#### 3. Connect to the network and access Aqara Studio

Wired connection is recommended: connect the M300 to a router/switch with an Ethernet cable, keep the PC on the same LAN, and open the address on the device management sticker in a browser (e.g., aqarastudio-EEFF.local) to access Studio.

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/M300-pic2.png" alt="Connect to Aqara Studio" style={{ width: '60%' }} />

On first use, initialize the admin username and password in the Studio web console. If initialization times out, reboot the device and try again (do not factory reset).

#### 4. Bind child devices

Bind Zigbee devices: see the Zigbee device add flow

Bind Matter Over Thread devices: see the Matter device add flow

### Button operations

| Operation | Description |
| -- | -- |
| Hold the function button for 10 seconds | Restore network parameters (available when anti-accidental-deletion is off; no response when on—red LED flashes 3 times quickly) |
| Press the function button 10 times quickly | Factory reset (available when [button factory-reset disable](./../../factory-reset.mdx#disable-button-factory-reset) is off; no response when on—red LED flashes 3 times quickly) |
| Press the function button once | Stop adding Zigbee child devices / stop voice playback |
| Press the function button 3 times quickly | Enter Zigbee child-device pairing (purple LED slow flash) |
| Press the function button 5 times quickly, then hold for 3 seconds | Enter network standby mode (disable Zigbee/Thread and other radios; solid purple; restored after power cycle) |

## Troubleshooting

### Symptoms, Possible Causes, and Solutions

Common configuration failures:

- After power-on, hold the function button for more than 10 seconds until the yellow LED flashes quickly, then retry;
- Confirm the device and PC are on the same LAN and enter the management address on the device correctly;
- Check whether the router has Wi-Fi anti-sharing / AP isolation enabled;
- Avoid bridged networks where possible;
- If first-time account initialization times out, reboot the device (do not factory reset) and restart initialization.

Unable to reset/factory-reset due to anti-accidental-deletion: Change the anti-accidental-deletion setting and the disable-button-factory-reset option in Aqara Studio, then try again.
