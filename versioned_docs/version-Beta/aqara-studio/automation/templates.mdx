# Templates

Aqara Studio lets you [convert](#generate-a-template) an existing automation or scene into a template so you can later [reuse it as the basis for a new automation or scene](#create-an-automation-or-scene-from-a-template).

You can also [export](#export-a-template) a template for local backup or [import](#import-a-template) it into another Aqara Studio instance.

## Generate a Template

To convert an automation or scene into a template:
1. In the automation list or scene list, find the item you want to convert, then click **... > Generate Template**.

    ![Convert to template](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Flow-GenerateTemplate.png)

2. In the dialog, enter a template name. Aqara Studio generates a default description, which you can edit as needed to further explain the template’s purpose.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Flow-DefineTemplateNameAndDescription.png" alt="Define template name and description" style={{width: '50%'}} />

3. When a success prompt such as **Template created successfully** appears, the automation or scene has been converted into a template. Switch to the **Templates** tab to see the newly converted template in the list.

    ![Template list](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Flow-TemplateList.png)


## Create an Automation or Scene from a Template

Creating an automation or scene from a template lets you quickly build a new automation or scene based on an existing template.

Follow these steps:
1. In the template list, find the template you want to use, then click **... > Use Template to Create**. You will enter the editor for the newly created automation or scene.

    ![Create an automation from a template](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Flow-UseTemplateToCreate.png)

2. Return to the **Automation** or **Scene** tab. You will see a new automation or scene added to the corresponding list.

    ![Check the new automation](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Flow-CheckNewFlow.png)

## Export a Template

In the template list, find the template you want to export, then click **... > Export** to download the template locally in JSON format.

![Export a template](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Flow-ExportTemplate.png)

## Import a Template

To import a local automation template JSON file into Aqara Studio, click the **Import** button on the **Template Management** tab to start the import.

![Import a template](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Flow-ImportATemplate.png)
