# Scenes

A scene stores multiple [action](./../flow/action.mdx) blocks and runs them together when the scene is activated. For example, a "Home" scene can turn on the lights and set the air conditioner to a comfortable temperature.

## When to Use a Scene

Use a scene when several device actions need to run together and you want to call that same set from more than one place.

For example, you can save actions such as turning on the lights and adjusting the air conditioner as "Home mode." You can then trigger it manually with a wireless switch, or have an automation run it after the door lock is unlocked, without configuring the same set of actions again.

If those actions are used only once in a single automation, you do not need to save them as a scene. Add the corresponding [action](./../flow/action.mdx) blocks directly in that automation.

## Create a Scene

In the left navigation bar, click **Automation**. Under the **Scene** tab, click the **Create** button.

![Click the Create button](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Scene-Create.png)
