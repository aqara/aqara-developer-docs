# BACnet

This document explains how to connect BACnet devices to Aqara Studio.

## Supported BACnet Object Types

When integrating a BACnet device with Aqara Studio, ensure that its point object types are supported by Aqara Studio, as listed below:

| Category | Object Types |
|----|----|
| Analog Objects | <ul><li>Analog Input</li><li>Analog Output</li><li>Analog Value</li></ul> |
| Binary Objects | <ul><li>Binary Input</li><li>Binary Output</li><li>Binary Value</li></ul> |
| Multi-state Objects | <ul><li>Multi-state Input</li><li>Multi-state Output</li><li>Multi-state Value</li></ul> |
| Additional Object Types | <ul><li>Integer Value</li><li>Binary Lighting Output</li><li>Channel</li><li>Color Temperature</li><li>Lighting Output</li><li>Color</li><li>Accumulator</li></ul> |

## Tested BACnet Devices

The following BACnet devices have been tested by Aqara and can be integrated with Aqara Studio:

| Brand | Model |

| Honeywell | HT9610P0100 |

## Prerequisites

Before you start, please make sure your network meets these conditions based on your device type:
- For BACnet/IP devices: The BACnet/IP device, Aqara gateway, and your computer must be on the same local area network (LAN).
- For BACnet MS/TP devices: The BACnet MS/TP device is already connected to a BACRouter, and the BACRouter, Aqara gateway, and your computer are all on the same LAN.

## Add Points

1. Under the BACnet IP node, select a BACnet device and click the **Add Point** button.

    ![Bacnet Point Page](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/BACnetIP-ClickAddPoint.png)

2. In the "Add point" page, click **Discover Points** button, Aqara Studio will begin scanning to discover function points for this device.

    :::tip
    If the system does not discover the function points you need, you can also [add them manually](#how-to-handle-bacnet-points-not-discovered-by-aqara-studio).
    :::

    ![Add points](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/BACnetIP-ClickDiscoverPoints.png)

3. Select the required points and click the blue "+" button. 

    ![Add points](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/BACnetIP-AddSelectedPoints.png)

4. You will then see the **Add Point** popup. In the left **Point** list, select a point.

    Aqara Studio will automatically associate the function point with a matching type in the Aqara Spec protocol based on the point type. In the left **Point Configuration** panel, find **Type Setting > Aqara Spec**, and confirm whether the recommended type matches the actual function of this point. If not, adjust it to the correct function point.

    ![Configure points](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/BACnetIP-ConfigurePoints.png)

    If the point of the BACnet device does not match the data type of the Aqara Spec point you selected, the system will trigger **Data Mapping**. Please configure the mapping relationship between the original value and the target value in the Aqara Spec in the **Data mapping rules**.

    ![Data Mapping](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/BACnetIP-DataMapping.png)

    After completing the configuration of one point, you can select other points in the **Point** list to continue configuring. After all function points are configured, click the **Complete** button to exit the function point configuration process.

5. Aqara Studio will automatically add the points. The newly added points will appear in the **Added Points** list on the right. Click the **Complete** button to exit the add point process.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/BACnetIP-PointsAdded.png" alt="Added Points" /> 

6. You will then see the added points on the BACnet device management page.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/BACnetIP-CheckPoints.png" alt="Points have been added" />

### How to Handle BACnet Points Not Discovered by Aqara Studio

If Aqara Studio does not find the points you need, please follow these steps to manually add them:
1. Return to the BACnet IP device management page, click the **Add Point** button.

    ![Bacnet Point Page](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/BACnetIP-ClickAddPoint.png)

2. Click the **Manually Add** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/BACnetIP-ClickManuallyAdd.png" alt="Manually Add" />

    In the **Add Point** popup, you can click the **+** button in the left **Point** list to manually add a point.

    After selecting the newly added point, you can configure its parameters. Details are as follows:
    - Point Add：

        | Parameter | Required | Description |
        | ---- | ------ | ---- |
        | Point Name | ✔ | You can customize the name of this point. |
        | Object Instance identifier | ✔ | The object instance identifier of this point. Range: [0, 4194303]. |
        | Object Type | ✔ | Object Type is a standard in Bacnet protocol used to define data point types, specifying the format, range, and meaning of data. You can read the description of this BACnet device to understand the object type of the point you need. |
        | Unit | ✘ | The unit for this point. |

    - **Type Setting**:
        - When the value of the point is **numeric**:   

            | Parameter Type  | Parameter Name | Required | Description | Example Configuration |
            |----------------|---------------|----------|-------------|----------------------|
            | Aqara Spec     | -             | ✔        | Associates this point with the corresponding function point in the Aqara Spec protocol for standardized control and management. | Air Conditioner/Heater Cooler/Set temperature |
            | Point Value (Number) | Min value | ✔     | The minimum value for this numeric function point. | 16 |
            |                | Max value       | ✔        | The maximum value for this numeric function point. | 30 |
            |                | Step          | ✔        | The step of the value range for this point. | 1 |
            |                | Unit          | ✔        | The unit of the value range for this point. | Celsius (℃) |
            |                | Precision     | ✔        | The precision of the value range for this point. Supported: <ul><li>Integer</li><li>1 decimal place</li><li>2 decimal places</li><li>3 decimal places</li></ul> | Integer |
            
        - When the value of the point is **boolean**:   

            | Parameter Type  | Parameter Name | Required | Description | Example Configuration |
            |----------------|---------------|----------|-------------|----------------------|
            | Aqara Spec     | -             | ✔        | Associates this point with the corresponding function point in the Aqara Spec protocol for standardized control and management. | Door and Window Sensor/Contact/Contact Status |
            | Point Value (Boolean) | True text | ✔   | Display text when the boolean function point value is `true`. | Closed |
            |                | False text    | ✔        | Display text when the boolean function point value is `false`. | Open |

    - **Data Mapping Rules**: After enabled, the original physical value can be recalculated and mapped to a status. Please refer to [Numerical Mapping Functions](./../numerical-mapping-functions.mdx) for more details.
        - When the **data area type** of the point is different from the **Aqara Spec type** (for example, a numeric type needs to be mapped to a boolean type, or a boolean type needs to be mapped to a numeric type), please enable this option to achieve conversion and mapping between the physical value and the standard function point type.
        - If the **data area type** of the point and the **Aqara Spec type** are the same, you do not need to enable this option.

3. After configuring all points, click the **Complete** button to exit the point adding process.
