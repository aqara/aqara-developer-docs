# Sonos

This document explains how to connect Sonos devices to Aqara Studio.

## Prerequisites

Before you begin, please ensure that you have successfully connected your Sonos devices to the same local network as Aqara Studio using the [Sonos App](https://support.sonos.com/en/downloads).

## Install the Plugin

Please refer to the [Plugin Market](./../plugin-center.mdx) instruction, and go to [Aqara Builder Lab - Marketplace](https://builder.aqara.com/lab/plugin-store) to install the `Sonos Protocol Access` plugin.

## Add a Sonos Device

1. In the left sidebar, click to enter the **Devices** page. In the left **Protocols and Devices** panel, click the **...** button and select **Add Protocol**.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Devices-AddProtocol.png" alt="Add Protocol" /> 

2. Select `Sonos Access` in the popup.   
    
    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Protocols-ChooseSonosAccess.png" alt="Select Sonos Access" style={{ width: '60%' }} /> 

3. Select `Sonos Access`, click the `Add Device` button.

    ![Discover Devices](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Sonos-ClickAddDevice.png)

    In the popup, select **Auto Discovery** and click the **Start connecting the device** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Sonos-SelectAutoDiscovery.png" alt="Select Auto Discovery" style={{ width: '60%' }} />

4. Click the “Discover Devices” button. Aqara Studio will then scan the network to find devices.

    ![Discover Devices](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Sonos-ClickDiscoverDevices.png)    

5. Select the device(s) you want to add, and click the "+" button in the center. 

    Newly added devices will appear in the **Added Device List** on the right. Click the **Complete** button to exit the add device process.

6. You will then see the successfully added devices under the Sonos Access node in the left **Protocols and Devices** panel, as well as in the device list on the Sonos Access management page.
