# TCP

This guide will show you how to integrate TCP protocol devices into Aqara Studio by writing JS scripts, and how to map device function points according to the **Aqara Data Model Specification**, enabling device discovery, addition, and control of function points.

## Tested TCP Devices

The following TCP devices have been tested by Aqara and can be integrated with Aqara Studio:

| Brand | Model |
|----|----|
| HOPE | Music Player MP1 <br /><strong>Note</strong>: Get the `HOPE Access` (HOPE speaker integration) plugin from [Aqara Builder Lab - Marketplace](https://builder.aqara.com/lab/plugin-store). Use it with the `TCP Protocol Access` plugin described below to simplify integration. You can then add HOPE speakers and their function points directly in the Aqara Studio web UI, without [writing a JavaScript script](#learn-and-write-javascript-scripts). |
| JBL | Home Theater/Karaoke Integrated Amplifier LM610 |
| Kudi | HA Video Box VP1 |

:::

## Learn and Write JavaScript Scripts

Please refer to the [JavaScript script (for UDP and TCP)](./../javascript-for-udp-tcp-integration.mdx) guide to write a JavaScript script that complies with the **Aqara Data Model Specification**. This script instructs Aqara Studio how to discover devices, and add and control function points.

## Install the Plugin

Please refer to the [Plugin Market](./../plugin-center.mdx) instruction, and go to [Aqara Builder Lab - Marketplace](https://builder.aqara.com/lab/plugin-store) to install the `TCP Protocol Access` plugin.

## Add TCP Devices

1. In the left sidebar, click to enter the **Devices** page. In the left **Protocols and Devices** panel, click the **...** button and select **Add Protocol**.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Devices-AddProtocol.png" alt="Add Protocol" /> 

2. In the popup, select `TCP` to add a TCP node.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Devices-SelectTCP.png" alt="Add TCP" style={{width: '70%'}} /> 

3. Select the node to enter the management page. Click the **Protocol Configuration** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-ProtocolConfiguration.png" alt="Protocol Configuration" /> 

4. In the popup, click the **Script Configuration** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-ScriptConfiguration.png" alt="Script Configuration" style={{width: '60%'}} /> 

5. Paste the [JavaScript script you wrote](#learn-and-write-javascript-scripts) into the code editor, ensuring that the TCP device and its function points can be correctly recognized and managed by Aqara Studio.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-ScriptEditor.png" alt="Paste the code into the script editor" style={{width: '60%'}} /> 

6. (Optional) If you want to use `msgId` to match sent messages with received messages, enable the `Match by msgId` switch. If it is not enabled, messages are processed in order.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-MsgIdMatch.png" alt="Message ID matching" style={{width: '60%'}} /> 

7. Return to the TCP management page and click the **Add Device** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-AddDevice.png" alt="Click the Add Device button" /> 

8. In the popup, select **Auto Discovery** as the integration method, then select **Start Integrating Device** to proceed to the next step.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-SelectAutoDiscovery.png" alt="Select Auto Discovery as the integration method" style={{width: '60%'}} /> 

9. (Optional) Click the ⚙ icon.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-Gear.png" alt="Click the gear icon" /> 

    If your TCP device is discovered via the TCP protocol, select the **TCP** option; if your TCP device is discovered via the UDP protocol, select the **UDP** option.

    :::tip
    If you do not use the following configuration, it is recommended to directly specify the target TCP device's IP address and port number in the return value of [parseDiscoveryResponse](./../javascript-for-udp-tcp-integration.mdx#parsediscoveryresponse) in the [JS script](#learn-and-write-javascript-scripts) to achieve precise device discovery and integration.
    :::

    - **TCP**:   
        Enter the target TCP IP address and port number in the popup. This information will be used by the [buildDiscoveryRequest](./../javascript-for-udp-tcp-integration.mdx#builddiscoveryrequest) interface in the [JS script](#learn-and-write-javascript-scripts) to instruct Aqara Studio to automatically discover all TCP devices at the specified address.   
        <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-TCPIPConfiguration.png" alt="Configure server IP address and Port" style={{width: '50%'}} />

    - **UDP**:   
        Set `Discovery Type` to `UDP`.   
        <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-DiscoveryType.png" alt="Configure discovery type" style={{width: '50%'}} />   
        Enter the UDP server IP address and port number in the popup. This information will be used by the [buildDiscoveryRequest](./../javascript-for-udp-tcp-integration.mdx#builddiscoveryrequest) interface in the [JS script](#learn-and-write-javascript-scripts) to instruct Aqara Studio to automatically discover all TCP devices at the specified address.    
        <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-IPConfiguration.png" alt="Configure server IP address and Port" style={{width: '50%'}} />

10. Click the **Discover Devices** button.

    Aqara Studio will automatically scan and identify TCP devices that can be integrated based on the [JS script](#learn-and-write-javascript-scripts) you wrote, and the discovered devices will be displayed in the **Discovered Devices** list.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-DiscoverDevices.png" alt="Discover Devices" /> 

11. Select the devices to integrate and click the **+** button in the center.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-AddDiscoveredDevices.png" alt="Add discovered devices" /> 

    Newly added devices will appear in the **Added Device List** on the right. Click the **Complete** button to exit the add device process.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-AddedDeviceList.png" alt="Added Device List" /> 


12. You will then see the successfully added devices under the TCP node in the left **Protocols and Devices** panel, as well as in the device list on the TCP management page.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-CheckAddedDevices.png" alt="Devices have been added" /> 

## Add Points

1. Under the TCP node, select a TCP device and click the **Add Point** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-SelectDeviceAndAddPoint.png" alt="Select a device and add points" /> 

2. Click the **Discover Points** button.

    :::tip
    - If the device function points are **dynamic**, implement the [buildDiscoverPointsRequest](./../javascript-for-udp-tcp-integration.mdx#builddiscoverpointsrequest) and [parseDiscoverPointsResponse](./../javascript-for-udp-tcp-integration.mdx#parsediscoverpointsresponse) interfaces in the [JS script](#learn-and-write-javascript-scripts).   
    In this case, when you click the **Add Point** button, Aqara Studio calls [buildDiscoverPointsRequest](./../javascript-for-udp-tcp-integration.mdx#builddiscoverpointsrequest) to dynamically discover device function points, and uses the return value of that interface as the input of [parseDiscoverPointsResponse](./../javascript-for-udp-tcp-integration.mdx#parsediscoverpointsresponse).
    - If the device function points are **static**, implement the [parseDiscoverPointsResponse](./../javascript-for-udp-tcp-integration.mdx#parsediscoverpointsresponse) interface in the [JS script](#learn-and-write-javascript-scripts), and **directly provide the target device's function-point list** in the return value.   
    In this case, when you click the **Add Point** button, Aqara Studio will discover these function points directly.
    :::

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-DiscoverPoints.png" alt="Discover Points" /> 

3. In the **Discovered Points** list, check the required points and click the middle **+** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-AddDiscoveredPoints.png" alt="Add discovered points" />
    
    Newly added points will appear in the **Added Points** list on the right. Click the **Complete** button to exit the add points process.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-AddedPoints.png" alt="Added Points" /> 

4. You will then see the successfully added points on the management page of that TCP device.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/TCP-CheckPoints.png" alt="Added points" />
