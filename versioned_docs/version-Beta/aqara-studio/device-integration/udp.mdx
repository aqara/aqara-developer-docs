# UDP

This guide will show you how to integrate UDP protocol devices into Aqara Studio by writing JS scripts, and how to map device function points according to the **Aqara Data Model Specification**, enabling device discovery, addition, and control of function points.

## Tested UDP Devices

The following UDP device has been tested by Aqara and can be integrated with Aqara Studio:
- Mantunsci smart circuit breakers

## Learn and Write JavaScript Scripts

For the shared script structure and configuration workflow, see the [third-party device script integration guide](../ai-agent-device-onboarding.mdx).

Please refer to the [JavaScript script (for UDP and TCP)](./../unified-protocol-script.mdx#tcp-udp) guide to write a JavaScript script that complies with the **Aqara Data Model Specification**. This script instructs Aqara Studio how to discover devices, and add and control function points.

## Install the Plugin

Please refer to the [Plugin Market](./../plugin-center.mdx) instruction, and go to [Aqara Builder Lab - Marketplace](https://builder.aqara.com/lab/plugin-store) to install the `UDP Protocol Access` plugin.

## Add UDP Devices

1. In the left sidebar, click to enter the **Devices** page. In the left **Protocols and Devices** panel, click the **...** button and select **Add Protocol**.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Devices-AddProtocol.png" alt="Add Protocol" /> 

2. In the popup, select `UDP` to add a UDP node.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Devices-SelectUDP.png" alt="Add UDP" style={{width: '70%'}} /> 

3. Select the node to enter the management page. Click the **Protocol Configuration** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/UDP-ProtocolConfiguration.png" alt="Protocol Configuration" /> 

4. In the popup, click the **Script Configuration** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/UDP-ScriptConfiguration.png" alt="Script Configuration" style={{width: '60%'}} /> 

5. Paste the [JavaScript script you wrote](#learn-and-write-javascript-scripts) into the code editor, ensuring that the UDP device and its function points can be correctly recognized and managed by Aqara Studio.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/UDP-ScriptEditor.png" alt="Paste the code into the script editor" style={{width: '60%'}} /> 

6. (Optional) If you want to use `msgId` to match sent messages with received messages, enable the `Match by msgId` switch. If it is not enabled, messages are processed in order.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/UDP-MsgIdMatch.png" alt="Message ID matching" style={{width: '60%'}} /> 

7. Return to the UDP management page and click the **Add Device** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/UDP-AddDevice.png" alt="Click the Add Device button" /> 

8. In the popup, select **Auto Discovery** as the integration method, then select **Start Integrating Device** to proceed to the next step.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/UDP-SelectAutoDiscovery.png" alt="Select Auto Discovery as the integration method" style={{width: '60%'}} /> 

9. (Optional) Click the ⚙ icon.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/UDP-Gear.png" alt="Click the gear icon" /> 

    :::tip
    [describe().discovery](../unified-protocol-script.mdx#tcp-udp-discovery) may specify a target or omit UDP IP for local broadcast calculation. Decode real replies into devices; use published manual creation if no discovery protocol exists. A static address list is not completed discovery.
    :::

    Enter the vendor unicast/broadcast/multicast destination and port or use script discovery settings. [encode(discoverDevices)](../unified-protocol-script.mdx#tcp-udp-discovery) builds requests; decode parses identity/communication addresses from responses.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/UDP-DiscoveryConfiguration.png" alt="Configure server IP address and Port" style={{width: '50%'}} />

10. Click the **Discover Devices** button.

    Aqara Studio will automatically scan and identify UDP devices that can be integrated based on the [JS script](#learn-and-write-javascript-scripts) you wrote, and the discovered devices will be displayed in the **Discovered Devices** list.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/UDP-DiscoverDevices.png" alt="Discover Devices" /> 

11. Select the devices to integrate and click the **+** button in the center.

    Newly added devices will appear in the **Added Device List** on the right. Click the **Complete** button to exit the add device process.


12. You will then see the successfully added devices under the UDP node in the left **Protocols and Devices** panel, as well as in the device list on the UDP management page.

## Add Points

1. Under the UDP node, select a UDP device and click the **Add Point** button.


2. Click the **Discover Points** button.

    :::tip
    - Remote point lists: encode(discoverPoints) sends bytes; decode returns [pointDefinitions](../unified-protocol-script.mdx#point-definitions) from the actual response.
    - Static point lists: encode(discoverPoints) returns null; decode receives bytes=null and returns pointDefinitions without a request.
    Both require selecting/importing points. Runtime option changes use [dynamic enums](../unified-protocol-script.mdx#dynamic-enums), not repeated point creation.
    :::

3. In the **Discovered Points** list, check the required points and click the middle **+** button.
    
    Newly added points will appear in the **Added Points** list on the right. Click the **Complete** button to exit the add points process.

4. You will then see the successfully added points on the management page of that UDP device.
