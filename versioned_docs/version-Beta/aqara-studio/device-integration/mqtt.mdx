# MQTT

This guide will show you how to integrate MQTT protocol devices into Aqara Studio by writing JS scripts, and how to map device function points according to the **Aqara Data Model Specification**, enabling device discovery, addition, and control of function points.

## Tested MQTT Devices

The following MQTT device has been tested by Aqara and can be integrated with Aqara Studio:
- Mantunsci smart circuit breakers

## Prerequisites

Before you begin, please ensure that the MQTT device to be integrated is already connected to an MQTT Broker.

## Learn and Write JavaScript Scripts

For the shared script structure and configuration workflow, see the [third-party device script integration guide](../ai-agent-device-onboarding.mdx).

Please refer to the [JavaScript script (for MQTT)](./../unified-protocol-script.mdx#mqtt) guide to write a JavaScript script that complies with the **Aqara Data Model Specification**. This script instructs Aqara Studio how to discover devices, and add and control function points.

## Install the Plugin

Please refer to the [Plugin Market](./../plugin-center.mdx) instruction, and go to [Aqara Builder Lab - Marketplace](https://builder.aqara.com/lab/plugin-store) to install the `MQTT Protocol Access` plugin.

## Add an MQTT Device

1. In the left sidebar, click to enter the **Devices** page. In the left **Protocols and Devices** panel, click the **...** button and select **Add Protocol**.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Devices-AddProtocol.png" alt="Add Protocol" /> 

2. In the popup, select `MQTT` to add an MQTT node.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Devices-SelectMQTT.png" alt="Add MQTT" style={{width: '70%'}} /> 

3. Select the node to enter the management page. Click the **Protocol Configuration** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-ProtocolConfiguration.png" alt="Protocol Configuration" /> 

4. In the popup, click the **Script Configuration** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-ScriptConfiguration.png" alt="Script Configuration" style={{width: '60%'}} /> 

5. Paste the [JavaScript script you wrote](#learn-and-write-javascript-scripts) into the code editor, ensuring that the MQTT device and its function points can be correctly recognized and managed by Aqara Studio. After completing it, click **Save**.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-ScriptEditor.png" alt="Paste the code into the script editor" style={{width: '60%'}} /> 

6. Return to the MQTT management page and click the **Add Device** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-AddDevice.png" alt="Click the Add Device button" /> 

7. In the popup, select **Auto Discovery** as the integration method, then select **Start Integrating Device** to proceed to the next step.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-SelectAutoDiscovery.png" alt="Select Auto Discovery as the integration method" style={{width: '60%'}} /> 

8. Click the **Discover Devices** button.

    Aqara Studio will automatically discover and identify MQTT devices that can be integrated based on the script you wrote, and the discovered devices will be displayed in the **Discovered Devices** list.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-DiscoverDevices.png" alt="Click the Discover Devices button" /> 

9. Select the devices to integrate and click the **+** button in the center.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-AddDiscoveredDevices.png" alt="Add discovered devices" /> 

    Newly added devices will appear in the **Added Device List** on the right. Click the **Complete** button to exit the add device process.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-AddedDeviceList.png" alt="Added Device List" /> 

10. You will then see the successfully added devices under the MQTT node in the left **Protocols and Devices** panel, as well as in the device list on the MQTT management page.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-CheckAddedDevices.png" alt="Devices have been added" /> 


## Add Points

1. Under the MQTT node, select an MQTT device and click the **Add Point** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-SelectDeviceAndAddPoint.png" alt="Select a device and add points" /> 

2. Click the **Discover Points** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-DiscoverPoints.png" alt="Discover Points" /> 

3. In the **Discovered Points** list, check the required points and click the middle **+** button.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-AddDiscoveredPoints.png" alt="Add discovered points" />
    
    Newly added points will appear in the **Added Points** list on the right. Click the **Complete** button to exit the add points process.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-AddedPoints.png" alt="Added Points" /> 

4. You will then see the successfully added points on the management page of that MQTT device.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-CheckPoints.png" alt="Added points" />

## FAQ

### How to Handle MQTT Device Data Points Not Discovered by Aqara Studio

If Aqara Studio does not detect the data points you need, please go to the "Add Point" page and click the "Manually Add" button. In the popup, enter the required parameters to manually add the point.

Detailed parameter descriptions are as follows:

| Parameter | Required | Description |
| --- | --- | --- |
| Friendly Name | ✔ | Data point ID. Please consult the device manufacturer for the real ID, so Aqara Studio can discover the point. |
| Point Name | ✘ | Custom name for the data point. |
| Dev Type | ✘ | Corresponds to `deviceType` in the Aqara Data Model Specification. Fill this in when defining points based on Aqara Spec. For available values, see [Aqara Spec Data Model Tags - Device Type List](../../aqara-developer/aqara-data-model-specification/aqara-data-model-tags.mdx#device-type-list). |
| Function Code | ✘ | Corresponds to `functionCode` in the Aqara Data Model Specification. Fill this in when defining points based on Aqara Spec. For available values, see [Aqara Spec Data Model Tags - Function Index](../../aqara-developer/aqara-data-model-specification/aqara-data-model-tags.mdx#ref_Aqara_Spec_FunctionIndex). |
| Trait Code | ✘ | Corresponds to `traitCode` in the Aqara Data Model Specification. Fill this in when defining points based on the Aqara Spec. For available values, see the relevant sections for each Trait in [Aqara Spec Data Model Tags](../../aqara-developer/aqara-data-model-specification/aqara-data-model-tags.mdx). |
| Data Type | ✘ | Data point type. Supported values:<ul><li><code>bool</code>: Boolean</li><li><code>numerical</code>: Numeric</li><li><code>text</code>: Text</li></ul>  |
| Access | ✘ | Access type:<ul><li>1: Read Only</li><li>2: Read/Write</li></ul> |
| Sub Topic | ✘ | Topic that Aqara Studio subscribes to for the latest data for this point. Please fill in according to the device protocol or manufacturer documentation. |
| Pub Topic | ✘ | Topic used by Aqara Studio to send messages to control this point. Please fill in according to the device protocol or manufacturer documentation. (For read-only points, leave this blank)  |
