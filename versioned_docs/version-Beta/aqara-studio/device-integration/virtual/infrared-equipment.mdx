# Infrared Equipment

This document introduces how to integrate infrared equipments into Aqara Studio, helping you conveniently manage and control infrared equipment via the Edge Hub M300.

## Supported Types

Currently, Aqara Studio supports the following types of infrared equipments:
- TV
- Set-top box
- DVD player
- Air conditioner
- Projector
- Audio/Speaker
- Fan
- Camera
- Smart light
- Air purifier
- Water heater
- Custom

## Create an Infrared Equipment

1. In the left sidebar, click to enter the **Devices** page. In the left **Protocols and Devices** panel, click the **...** button and select **Add Protocol**.   
    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Devices-AddProtocol.png" alt="Add Protocol" /> 
2. In the pop-up window, select `Virtual` to add a `Virtual` node.   
    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Devices-SelectVirtual.png" alt="Select Virtual" style={{width: '70%'}} /> 
3. Select this node and click the `Add Device` button.   
    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Virtual-AddDevice.png" alt="Add Device" /> 
4. In the pop-up window, set the **Virtual Device Type** to **Infrared Equipment**, and configure the **Name** of the device.   
    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-ConfigureVirtualTypeAndName.png" alt="Configure virtual device type and name" style={{width: '60%'}} /> 
5. Select the **Infrared Equipment Type** and its brand.    
    ![Select infrared equipment type](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-SelectTypeandBrand.png)

    If the device type is not in the list or is a custom device, select **Customize**. Then click **Next Step** to enter the [infrared learning process](#infrared-learning).
    ![Select custom device type](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-CustomDevice.png)

6. Aqara Studio will start downloading all code libraries for devices of this brand and type. 

## Match Code Libraries

7. Once the download is complete, select the applicable code library, and select the **debug gateway** (used to send infrared commands to control the infrared equipment to be integrated, such as the Edge Hub M300).
    ![Select code library and debug gateway](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-SelectCodesandGateway.png)
8. Click an infrared command. The **Debug Gateway** above will **flash a blue light**. Observe whether the infrared equipment to be integrated responds.
    If the device responds, it means this command can be used to control the infrared equipment. Click the **responsive** button.   
    If the device does not respond, it means this command cannot be used to control the infrared equipment. Click the **No Response** button.   
    ![Test infrared command](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-TestCodes.png)

### Infrared Learning

9. Besides using the preset infrared code libraries above, if the device has more infrared function points, you can add the required function points through the **Infrared Learning** feature.
    Click the **Add function points** button to open the **Add Button** pop-up window.
    ![Click the Add Function Point button](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-AddFunctionPoint.png)   
    
    In the pop-up window, define the **name** and **device type** of this function point, then point the remote controller of the infrared equipment at the **debug gateway**, and press a button on the remote.    
    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-AddKeyPopup-1.png" style={{ width: '60%' }} />

    After successful learning, the pop-up will prompt **Functional learning successful**. Click the **Confirm** button to finish adding.   
    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-StudySuccess.png" style={{ width: '60%' }} />

    Newly added function points will appear in the **Infrared learning function** area.   
    ![New function point](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-NewPoints.png)

## Complete Device Integration

10. After completing [infrared code library matching](#match-code-libraries) and [adding all infrared function points](#infrared-learning), click the **Confirm** button to complete the device integration process.
    ![Confirm completion of infrared code library matching and infrared learning](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-ConfirmAddition.png)
11. At this point, you will see the successfully added device under the `Virtual` node in the left **Protocols and Devices** panel, as well as in the device list on the `Virtual` management page.

    :::tip
    At this point, you will find that the device is offline. The device still needs to be [associated with a gateway](#associate-a-gateway) before it can be controlled.
    :::

    ![Return to device details](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-CheckAddedDevice.png)

## Associate a Gateway

Completing the above device integration and infrared command addition does not mean you can immediately control this device. You still need to associate the infrared equipment to the **Debug Gateway**. The process is as follows:
1. Under the `Virtual` node in the left **Protocols and Devices** panel, select the device added above and click **Device details**.   

    ![View device details](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-CheckDeviceDetails.png)

2. Switch to the **Device Configuration** tab, find the **associated configuration**, select the  **debug gateway**, and click the **Associate** button.

    :::tip
    After associating the gateway, the infrared matching content will be automatically locked and cannot be modified again. Please confirm that the matching plan is accurate before delivery.
    :::

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-SwitchToDeviceConfigurationandChooseHub.png" alt="Switch to the Device Configuration tab" style={{width: '60%'}} />

3. After successful delivery, you can see that the infrared code library status is **Already Effective**, and the device online status is **Online**.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-CodeValidandOnline.png" alt="Infrared code library status is effective and device online status is online" style={{width: '60%'}} />

4. Return to the **Device Details** tab. You can see that the **Command Control** area has been added. This is the matched infrared code library, and you can control the infrared equipment here.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-CheckCommands.png" alt="View command control" style={{width: '60%'}} />

5. Return to the **Device** page. You can see that the **Point** list now includes the custom infrared function point (trait), and you can also control the infrared equipment here.

    ![View custom function point](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/IR-CheckTraits.png)
